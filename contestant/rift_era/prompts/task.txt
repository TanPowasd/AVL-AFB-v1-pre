## 2. 一句话规则

8 个大国在一张 **512×512** 大陆地图上实时经营 **28,800 tick**（4 纪元 × 720 周期 × 10 tick，每 5 tick 一个决策窗口），统筹民生、工业、能源、物流、科研、金融、外交与军事；终局按四纪元加权与可持续性系数 `Φ` 算出精确国力 **`V`**，与同地图同席位不公开多风格强评分对手混编影子局的 `V_shadow` 比较：

```text
vtilde(V) = V + 10            (V >= 0)
          = 100 / (10 - V)    (V < 0)
R         = vtilde(V_player) / vtilde(V_shadow)
score     = 50 + 50 * tanh(0.6 * ln R)
```

## 3. 硬约束（违反 = 托管或判零）

- **标准库唯一**：`make_submission.py` 会静态检查第三方 `import`；`sdk.py` 必须原样复制进提交包。
- **窗口协议**：开局收到 `init` 后 **15 秒内**调用 `client.ready()`；每个 `obs` 窗口必须回复相同 `window` 编号，每窗口最多 **256 条**命令。
- **严禁进程崩溃**：策略内部任何异常必须 `try/except` 捕获并返回 `[]`；进程退出即本局剩余窗口全部托管为空命令。
- **思考时间预算**：每窗口基础 **0.5 秒**，超出部分扣 **450 秒 `time_pool`**；单窗口硬上限 **30 秒**；整局总思考上限 **3600 秒**；超时达 **50 次**或预算耗尽即被托管为空命令。
- **合法命令拒绝**：非法命令仅返回 `ERR_*` 并被忽略，不影响同窗口其他合法命令，但请勿刷无效指令浪费配额。

## 5. 六个高频踩坑点（先看省半天）

1. **首都断粮 / 断水 / 断药**：开局药品缓冲区约 160 周期耗尽，且缺粮断水会同时重创人口支柱与可持续性系数 `Φ`（最低跌至 `0.35`，直接腰斩终局权重）。
2. **仓库爆满卡死全链**：公共仓容满时制造与民生产出都放不进去；务必用 `industry/set_line` 设合理的 `target_stock_mU`，并用余料适度扩仓（注意空置扩仓不加 `Kinfra`）。
3. **无脑囤货触发 `eta` 折损**：逐国家逐物品计算库存/20期均耗比 `chi`，`chi > 6` 时有效增加值折损直至归零（且军事消耗/损毁会永久累入只读 `SinkDebt`）。
4. **盲目盖空壳厂与电站空烧**：已建成但全部产线未装机空置的工厂 `Kinfra` 只按 `0.25` 计；煤电最低出力 40%，富余电站不关（`industry/plant_toggle`）会白烧煤、增污染。
5. **科研只做理论不做验证 / 单实验室排队**：科技理论进度满后必须发 `research/validate_project` 才会真正解锁；尽早利用富裕工程师多建实验室并行冲刺关键科技。
6. **无收益的敌对行动**：任何军事射击、行军、封锁、网络/反卫星等敌对消耗都强制按目录值计入 `Loss_action` 严格扣减自身 `V`，只有带来更大独立实益（领土、资源、贸易）时才值得发动。

# 裂陆纪元（rift_era）公开赛制说明

本文件仅包含公开赛制与执行约束。完整规则全文见 `rules/`，命令列表见 `COMMANDS.md`。

- **赛题**：裂陆纪元（`rift_era`），8 国实时宏微观经济、科技、金融、外交与军事策略对抗。
- **地图与时钟**：`512 × 512` 双层地理空间（L1 地块 + L2 分区/枢纽/走廊）；正式局 **28,800 tick**（4 个战略纪元 × 720 周期 × 10 tick），每 **5 tick** 一个同步决策窗口（共 5,760 窗口）。
- **计分口径（0–100 连续分）**：
  - 每次正式评测由操作系统安全随机源抽取 **64 个互异随机 seed**。对第 `k` 个 seed，先跑一局由 `N = 3` 位参考对手按确定性 8 席阵容（被替换席位 `seat = k mod 8`，被替换参考对手 `shadow_idx = (k + k // lcm(N, 8)) mod N`，其余 7 席按 `shadow_idx` 循环均布）坐镇的**影子局**，再仅将 `seat` 席替换为你的提交跑**正式局**，以精确有理数与自适应精度区间比较同一席位国力 `V`：
    - `vtilde(V) = V + 10`（`V >= 0`），否则 `100 / (10 - V)`
    - `R = vtilde(V_player) / vtilde(V_shadow)`
    - `score = 50 + 50 * tanh(0.6 * ln R)`
  - 与被替换参考对手持平得 `50.00` 分；最终正式成绩取全部 **64 局等权均值**并附 95% 种子块 bootstrap 置信区间。国力 `V = 0.08·U_I + 0.14·U_II + 0.24·U_III + 0.29·U_IV + 0.25·U_end_adj`（完整五支柱与可持续性系数公式见 `rules/07_scoring_and_resources.md`）。
- **提交格式**：单个 `.zip` 文件，根目录必须包含 `main.py`（使用 `sdk.py` 时须原样打入包内）；压缩包 ≤ 512 MiB，解压 ≤ 2 GiB / 4096 文件。统一交卷路径为 `../submissions/rift_era.zip`，本地打包可用 `agents/submissions/my_bot.zip`。
- **运行时隔离与限制**：
  - 仅允许 Python 3.11+ 标准库，无网络访问；
  - 内存上限 1 GiB，可写工作区上限 64 MiB；
  - 开局握手限时 15 秒；每窗口基础思考 0.5 秒，超额扣 450 秒 `time_pool`，单窗口硬上限 30 秒，整局总计 3,600 秒；
  - 超时 50 次、`time_pool` 或总时长耗尽、或进程异常退出，本局剩余窗口全部托管为空命令；
  - 每窗口最多提交 256 条命令；非法命令只被逐条拒绝（返回 `ERR_*`），不影响同窗口其余合法命令。
- **本地练习与合规边界**：
  - 选手包提供 `none`、`simple`、`template`、`medium`、`advanced` 作为公开练习对手，因公开对手数量不足以凑齐 8 席对局中的 7 个不同对手，**需要选手自行制作多风格/多版本对手 bot（含自身镜像）并通过 `local_match.py` 的 `--seats` / `--opponent` 进行充分自测**；
  - `medium` 与 `advanced` 仅用于本地练习，不等于正式评分基准；
  - 所有本地测试输出、回放与日志应保留在当前工作区的 `results/`、`replays/`、`logs/` 内；选手工作区禁止启动 HTTP 共享服务，也不得修改 `runtime/`、`rules/`、`sdk.py` 或 `config/workspace.json`。

# 裂陆纪元（rift_era）选手手册

本手册面向参赛开发者与编程 AI，集中说明通信协议、观测结构、命令写法、策略开发路径与本地验证流程。

## 1. 提交结构与入口契约

提交物是一个 `.zip` 压缩包，根目录必须包含 `main.py`。典型目录结构：

```text
my_bot/
  main.py     # 入口：初始化 Client -> 接收 init -> ready() -> 决策循环
  bot.py      # 你的核心策略类 Bot(init).decide(obs)
  sdk.py      # 从选手包根目录原样复制的标准库客户端
```

评测机在隔离环境运行 `python3 main.py`，通过 `stdin`/`stdout` 逐行收发 JSON（`rift_jsonl_v1`）。`sdk.py` 已经封装好大帧分页重组、窗口号绑定与递增命令编号：

```python
from sdk import Client
from bot import Bot

client = Client()
init = client.receive()   # 含 owner, map, catalog, initial_observation, clock, time_budget
bot = Bot(init)
client.ready()            # 必须在 15 秒内回复
while True:
    msg = client.receive()
    if msg.get("type") == "end":
        break
    try:
        orders = bot.decide(msg)
    except Exception:
        orders = []       # 切勿让异常导致进程退出
    client.orders(msg["window"], orders[:256])
```

## 2. 开局帧（`init`）与每窗口观测（`obs`）

- **`init` 帧关键字段**：
  - `owner`：本国 ID（`"n0"` .. `"n7"`）。
  - `map`：公开 512×512 地理编码（`width`, `height`, `map_version`, `region_palette`, `region_rle_rows`, `terrain_by_region`, `elevation_by_region`, `fertility_by_region`, `wind_by_region`, `cloud_by_region`, `adjacency`, `hubs`, `routes`, `river_downstream`, `coastal_hubs`）。注意开局不含隐藏矿藏与随机种子。
  - `catalog`：完整的只读规则目录（`technology`, `industry`, `coupling`, `scoring`, `runtime_rules`, `military`），包含全部科技前置、工业配方、产线定额、影子权重 `w_cat` 与军品参数。
  - `initial_observation`：第 0 拍的初始观测帧。
  - `clock` / `time_budget`：总 tick、窗口间隔（5）、周期长度（10）与思考计时预算。
- **`obs` 帧关键字段**（每 5 tick 下发一次，仅含本国可见信息与传感器过滤情报）：
  - `window`, `tick`, `cycle`：当前窗口、仿真步与周期编号。
  - `inventory`：本国库存列表，行格式 `[hub_id, bucket, good, qty_mU]`（`bucket` 如 `available`、`locked_subsistence`、`locked_order` 等；`1 单位 = 1000 mU`）；另附 `inventory_economic_titles_nmU` 与 `food_synthetic_shares_mU`。
  - `cash_accounts` / `treasury_mU`：`cash_accounts` 为本国各账户列表 `[account_name, currency, balance_mU]`（如 `["treasury", "n0", ...]`、`["household:n0-h0", "n0", ...]`、`["reserves", "RU", ...]` 等）；`treasury_mU` 为国库本币余额快捷值。
  - `hubs` / `population_mU`：`hubs` 为各可见枢纽对象列表（含 `id`, `region_id`, `population_mU`, `skills_mU` (`general_worker`/`skilled_worker`/`engineer`), `training_population_mU`, `housing_mU`, `warehouse_mU`, `support_mU`, `warning`, `red_streak`, `pollution_mU`, `satisfaction_mU`, `grid_price_ru_mU`, `household_cash_mU`, `public_cash_mU`）；`population_mU` 为全国平民人口总计。
  - `facilities` / `lines` / `mines` / `storage` / `systems` / `work`：设施、产线（电站同样在 `lines` 列表中，带 `plant` 子对象，无独立 `plants` 键）、采掘点、储能、公共系统与在建工程队列。
  - `research`：`known`（已解锁科技）、`projects`（理论与验证进度）、`focus`（各实验室绑定目标）、`security`（保密档位）与 `validation`（进行中的验证任务）。
  - `markets` / `market_fills` / `world_pool` / `export_controls` / `fx_fills`：现货报价与成交记录、世界池挂牌与限额、出口管制及汇兑成交。
  - `macroeconomy` / `governance` / `utilities` / `power_policy` / `sovereign_finance` / `corporate_finance` / `bond_market` / `stock_market` / `forward_finance` / `external_payables` / `insolvency`：宏观 CPI/汇率/利率/通胀、税率与预算、电力调度政策与主权/公司/债股/远期金融账本。
  - `diplomacy` / `contracts` / `city_states` / `formations` / `military_contacts` / `military_control` / `strikes` / `orbital` / `orbital_contacts` / `shared_intelligence`：外交关系（`pairs`, `war_spread_bp`）、合同、中立城邦、本国编队、迷雾内可见敌情（含在途运输接触 `strikes.shipment_contacts`）、轨道与共享情报。
  - `command_receipts`：上一窗口命令的执行回执列表（每项含 `id`, `status` (`"ACCEPTED"`/`"REJECTED"`), `code` (`null` 或 `ERR_*` 错误码)）。

详细字段定义与迷雾边界请以 `rules/06_agent_interface.md` 为准。

## 3. 命令格式与高频指令

每条命令均是含唯一递增字符串 `id`、`kind`、`op` 及操作参数的字典，每窗口最多 **256 条**：

```json
{"id": "1", "kind": "research", "op": "set_focus", "line_id": "n0/P075/0/line", "tech_id": "I02", "sec_mode": "standard"}
```

## 4. 策略开发建议路线

1. **稳住底座（零崩盘）**：实时监控首都及人口枢纽的 `food`、`water`、`medicine`、`consumer_goods`、`electricity` 满足度，出现缺口优先从市场或世界池（`trade/pool_buy`）补货，避免触发低 `Φ` 惩罚。
2. **控库存与仓容**：按“民生消耗 + 下游产线消耗”动态设置产线 `target_stock_mU`，既防止仓库爆满阻塞产出，又防止过度囤货导致 `chi > 6` 触发 `eta` 折损。
3. **能源与排放优化**：根据实时用电负荷开关冗余煤电（`plant_toggle`），减少燃煤浪费与污染扣分，尽早向高效能源科技过渡。
4. **科研加速度与技术落地**：尽早扩建实验室、培养工程师、并行解锁高权重科技链；**解锁后必须实际运行对应配方/设施/算力以拉满 `ActiveScale`**（仅解锁无落地只拿 15% 科技分！）。
5. **多枢纽扩张、贸易与金融**：开发 `h1..h4` 与优质矿脉、打通走廊物流赚取 `NetTransit` 与出口分、稳健管理主权债与城邦结盟。
6. **算力节流**：将重规划放在每 N 个窗口（如每 2~10 窗口）执行一次，保证平均单窗口耗时 < 50 ms。

# 裂陆纪元（rift_era）游戏事实卡

本事实卡提炼自正式规则 `rift_era_rules_r9`（`rules/01`–`07`、`10`、`11` 与 `rules/data/*.json`）。如与细节有出入，以 `rules/` 和本包附带的 `runtime/` 引擎为准。

## 1. 时钟、纪元与精度

- **最小单位**：全部实物、现金、电量、研究点、人口使用整数毫单位（`1 单位 = 1,000 mU`）；产线信用与在制品使用纳单位（`1 mU = 1,000 nmU`）；金额成本与国力评分内部采用精确有理数（`Fraction`）。
- **三级时钟**：
  - `1 Window（决策窗口）= 5 Tick`（每 `t % 5 == 0` 同步交互，整局共 **5,760 窗口**）；
  - `1 Cycle（工业与财政周期）= 10 Tick = 2 Window`（整局共 **2,880 周期**）；
  - **正式总长**：`28,800 Tick`（本地练习 `--ticks` 须为 40 的正整数倍）；
  - **四个战略纪元**：每纪元 `720` 周期（奠基 / 扩张 / 转型 / 决胜），期末可持续窗口为最后 `40` 周期；设施定期维护每 `20` 周期结算一次（整局 144 次）。

## 2. 同 Tick 八阶段流水线（与座位顺序无关）

每 tick 严格按 `P1 → P8` 推进，同阶段竞争共享资源池统一采用**无偏等比分配 + 确定性哈希尾差**：

1. **P1 命令与生存预留**：按固定优先级（托管刚兑 → 现役部队口粮 → 水电农基础运行 → 居民口粮饮水）自动锁定 `locked_subsistence`；仅 `t % 5 == 0` 接入玩家命令（每窗口 ≤ 256 条），卖单/施工立即锁仓锁款。
2. **P2 环境与物流**：更新天气/水文；推进走廊货运与客运，抵达货物当拍进入 `available`。
3. **P3 电网供需**：扣燃煤/油/氢/核料与冷却水，扣除距离线损后按 `B0–B5` 六档优先级配电（煤电最低出力 40%）。
4. **P4 移动与同时交战**：仅处于 `WAR` 状态的两国发生交战；同时结算火力、行动损耗（`Loss_action`）与附带战损。
5. **P5 市场出清**：`t % 5 == 4` 执行各地现货双边集合竞价与世界池撮合；`t % 10 == 9` 执行证券出清；成交货物进入 `next_available`。
6. **P6 生产、采掘、科研与施工**：仅使用未锁定的 `available`；出库仓容分两遍仲裁（**r9：制造产线优先于采掘线入仓**），产出写入 `next_available`（次 tick 可用，杜绝同拍级联）。
7. **P7 周期结算与缓冲合并**：消费、发薪、征税、分红、支持度、人口增长、宏观利率汇率与国力周期采集；最后把 `next_available` 合并进 `available`。
8. **P8 观测生成**：更新已验证科技解锁并按迷雾与权限过滤生成下一窗口 `obs`。

## 3. 世界规模与开局禀赋

- **空间尺度**：`512 × 512` L1 栅格 + `24 × 20` 战略分区（340–420 陆地 + 80–120 海洋，2–4 块大陆），8 个主要国家（每国 18–24 相连初始分区、5 座核心枢纽 `h0..h4`）、36–48 个中立城邦、220–280 座枢纽、1,100–1,500 条走廊边、24 个近地轨道槽位。
- **开局模板（集中于首都 `h0`）**：
  - 人口 200：194 平民（普工 144、技工 40、工程师 10）+ 6 军人（2 支驻防编队）；
  - 设施：27 座 S1（24 生产设施 + 3 住宅）+ 1 座 S2 基础药品线（`P033`，开局按 0.5 批运行）+ 9 座 G1 采掘点；
  - 仓容 `3,300`（基础 300 + 6 个 500 模块），住宅容量 `300`，3 辆未部署物流车；
  - 资金：国库 `100,000` 本币 + 居民池 `50,000` 本币（开局各币汇率 `e0 = 1`，冻结 `InitialCashBookRU = 150,000`）；
  - 民生单人每周期基准需求：`food 0.06`、`water 0.04`、`consumer_goods 0.03`、`medicine 0.01`、`medical_supplies 0.0025`、`electricity 0.02`。无命令开局药品库存约 160 周期耗尽，可用 `trade/pool_buy` 向世界池应急采购。

## 4. 精确国力 `V` 与五支柱公式

每周期国力总值：
```text
U = 0.25 * U_pop + 0.25 * U_ind + 0.20 * U_ctrl + 0.15 * U_tech + 0.15 * U_intl
```

1. **人口支柱 `U_pop`**：`100 * sum_r(psi * Pop_civ / 200 * Qlife * Qsec)`
   - 本土合法性 `psi ∈ [0.5, 1.0]`，占领区 `psi ∈ [0.15, 0.5]`（需驻控 40 周期逐步抬升）；
   - `Qlife` 依赖食品（合成食品占比超 30% 会折损）、民用品、药品/医疗用品、水电；`Qsec` 受战斗、封锁与污染扣减。
2. **工业支柱 `U_ind`**：`0.35 * (sum VA_eff - Loss_destroy - Loss_action + 0.05 * NetTransit + NFA_RU / 1000)`
   - 仅非采掘制造线计 `VA_eff`；
   - **过量囤货折损 `eta`**（逐国逐物品独立计算）：`chi = (I_physical_eta + SinkDebt) / max(1, mean_n(eligible_consumption))`（r9 永久豁免未耗尽的开局非回填禀赋余量），`chi <= 6` 时 `eta = 1`，否则线性降至 `0`（`chi >= 12` 归零）；
   - **`Loss_action` 严格自身损耗**：作战、行军、封锁、网攻、反卫星等实际耗材与算力按目录值计损（单事件最低 `0.001`），固定影子下任何无额外实益的敌对行动均使自身 `V` 严格下降；
   - **`NFA_RU` 历史成本账面**：基于冻结历史 RU 成本，单纯操控本币汇率无法虚增 NFA。
3. **控制支柱 `U_ctrl`**：`sum_connected(sigma_r) + 0.01 * Kinfra + 2 * min(8, N_sat) + 0.20 * min(MilCap, sum V_ready)`
   - 仅计与首都或有粮+通信设备的备份核心枢纽**补给连通**的受控区；
   - **r7/r9 `Kinfra` 细则**：公共仓库扩建模块按**实际占用率**计入（空扩仓不加分）；已建成非住宅空壳设施（全产线 `__idle__` 且未装机）仅按 `0.25` 计。
4. **科技支柱 `U_tech`**：`0.60 * sum_known(W_t * (0.15 + 0.85 * min(1, (ActiveScale + 0.5 * LicensedScale) / theta)))`
   - 仅解锁科技不落地只得 15% 分；必须通过对应配方、在线设施或有效算力达成 `ActiveScale >= theta` 才能拿满 100%。
5. **国际支柱 `U_intl`**：`0.08 * mean20(credit_weighted_exports) + 2.5 * Credit * aligned_cities + 0.05 * mean20(credit_weighted_aid)`
   - 出口与运输贡献仅在**不可逆真实末端消费**时确认，转仓、贸易倒手不刷分。

## 5. 四纪元轨迹、可持续系数 `Φ` 与百分制

- **可持续系数 `Φ ∈ [0.35, 1.0]`**：
  `Φ = max(0.35, 1 - d_maint - d_short - d_unrest - d_insolvency)`，扣项来自期末平均维护欠账、末 20 期食电缺口、受控人口橙红警比例、永久违约次数与末 40 期违约/脱锚事件。
- **有符号期末调整与总国力 `V`**：
  - `U_end_adj = max(U_end, 0) * Φ + min(U_end, 0) * (2 - Φ) - 10 * (1 - Φ)`
  - `V = 0.08 * U_I + 0.14 * U_II + 0.24 * U_III + 0.29 * U_IV + 0.25 * U_end_adj`
- **六维独立产权账本**：军事占领（清空守军且驻满 10 tick）只改变军事控制 `controller`（军管敌国资产产能上限 60%），不没收主权或第三方股权；强行国有化立扣国际信用 `-0.30`。

============================ 起步入口模板 main.py ============================

```python
"""裂陆纪元提交入口：评测机在沙箱里运行 `python3 main.py`。只能用 Python 标准库。

协议由 sdk.py 处理（分页、窗口号、命令 id）。你只需要改 bot.py 里的 Bot.decide。
"""
import os
import sys
import traceback

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from sdk import Client  # noqa: E402  （与选手包根目录 sdk.py 相同，必须一起打进 zip）
from bot import Bot  # noqa: E402


def main():
    client = Client()
    init = client.receive()          # 开局：公开地图、目录（科技/配方/军品）、本国初始观测、时钟、时间预算
    bot = Bot(init)
    client.ready()                   # 15 秒内必须回 ready
    while True:
        message = client.receive()   # 每个决策窗口一帧本国过滤观测
        if message.get('type') == 'end':
            return
        try:
            orders = bot.decide(message)
        except Exception:            # 策略 bug 不要让整个进程崩溃（崩溃会被托管为空命令）
            traceback.print_exc(file=sys.stderr)
            orders = []
        client.orders(message['window'], orders[:256])   # 每窗口最多 256 条


if __name__ == '__main__':
    main()
```

============================ 起步策略模板 bot.py ============================

```python
"""模板策略：科研不断档 + 首都粮食兜底。在此基础上改进。

观测字段说明见选手包 rules/06_agent_interface.md；命令表见 COMMANDS.md。
"""

FOOD_FLOOR_MU = 400_000      # 首都粮食低于 400 单位（1 单位 = 1000 mU）就去本地市场买
FOOD_BID_PRICE_MU = 60_000   # 限价（mU 本币/单位）


class Bot:
    def __init__(self, init):
        self.owner = init['owner']
        tech = init.get('catalog', {}).get('technology', {})
        self.nodes = {row['id']: row for row in tech.get('technologies', ())}
        self.seq = 0

    def order(self, kind, op, **fields):
        self.seq += 1
        return {'id': str(self.seq), 'kind': kind, 'op': op} | fields

    def researchable(self, tech_id, known):
        row = self.nodes[tech_id]
        need_all = set(row.get('requires_all') or ())
        need_any = set(row.get('requires_any') or ())
        return tech_id not in known and need_all <= known and (not need_any or need_any & known)

    def decide(self, obs):
        orders = []
        research = obs.get('research', {})
        known = set(research.get('known', ()))
        projects = research.get('projects', {})
        focus = research.get('focus', {})
        busy = {j['lab_id'] for j in research.get('validation', ()) if j.get('active')}
        claimed = set(focus.values())
        # 1) 每座实验室（配方 P075 的产线）：理论完成就验证，否则研究最低阶的可研究科技
        for line in obs.get('lines', ()):
            if line.get('recipe') != 'P075' or line.get('under_construction') or line['id'] in busy:
                continue
            current = focus.get(line['id'])
            project = projects.get(current, {}) if current else {}
            if current and project.get('theory_complete') and not project.get('verified'):
                orders.append(self.order('research', 'validate_project', line_id=line['id'], tech_id=current))
                continue
            if current is None or current in known or project.get('verified'):
                options = sorted((self.nodes[t]['tier'], t) for t in self.nodes
                                 if self.researchable(t, known) and t not in claimed)
                if options:
                    claimed.add(options[0][1])
                    orders.append(self.order('research', 'set_focus', line_id=line['id'],
                                              tech_id=options[0][1], sec_mode='standard'))
        # 2) 首都（Hub id 以 -h0 结尾）粮食兜底：库存行格式 [hub, 状态, 物品, 数量mU]
        inventory = obs.get('inventory', ())
        capital = next((r[0] for r in inventory if len(r) == 4 and str(r[0]).endswith('-h0')), None)
        food = sum(r[3] for r in inventory if len(r) == 4 and r[0] == capital and r[1] == 'available' and r[2] == 'food')
        if capital and food < FOOD_FLOOR_MU and obs.get('window', 0) % 2 == 0:
            orders.append(self.order('logistics', 'market_bid', region_market=capital, good='food',
                                     qty_mU=FOOD_FLOOR_MU - food, limit_price_mU=FOOD_BID_PRICE_MU, expire_cycles=1))
        return orders
```
