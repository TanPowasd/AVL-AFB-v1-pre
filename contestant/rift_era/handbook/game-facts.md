# 裂陆纪元（rift_era）游戏事实卡

本事实卡提炼自正式规则 `rift_era_rules_r9`（`rules/01`–`07`、`10`、`11` 与 `rules/data/*.json`）。如与细节有出入，以 `rules/` 和本包附带的 `runtime/` 引擎为准。

## 1. 时钟、纪元与精度

- **最小单位**：全部实物、现金、电量、研究点、人口使用整数毫单位（`1 单位 = 1,000 mU`）；产线信用与在制品使用纳单位（`1 mU = 1,000 nmU`）；金额成本与国力评分内部采用精确有理数（`Fraction`）。
- **三级时钟**：
  - `1 Window（决策窗口）= 5 Tick`（每 `t % 5 == 0` 同步交互，整局共 **5,760 窗口**）；
  - `1 Cycle（工业与财政周期）= 10 Tick = 2 Window`（整局共 **2,880 周期**）；
  - **正式总长**：`28,800 Tick`（本地练习 `--ticks` 须为 40 的正整数倍）；
  - **四个战略纪元**：每纪元 `720` 周期（奠基 / 扩张 / 转型 / 决胜），期末可持续窗口为最后 `40` 周期；设施定期维护每 `20` 周期结算一次（整局 144 次）。

## 2. 同 Tick 八阶段流水线（与座位顺序无关）

每 tick 严格按 `P1 → P8` 推进，同阶段竞争共享资源池统一采用**无偏等比分配 + 确定性哈希尾差**：

1. **P1 命令与生存预留**：按固定优先级（托管刚兑 → 现役部队口粮 → 水电农基础运行 → 居民口粮饮水）自动锁定 `locked_subsistence`；仅 `t % 5 == 0` 接入玩家命令（每窗口 ≤ 256 条），卖单/施工立即锁仓锁款。
2. **P2 环境与物流**：更新天气/水文；推进走廊货运与客运，抵达货物当拍进入 `available`。
3. **P3 电网供需**：扣燃煤/油/氢/核料与冷却水，扣除距离线损后按 `B0–B5` 六档优先级配电（煤电最低出力 40%）。
4. **P4 移动与同时交战**：仅处于 `WAR` 状态的两国发生交战；同时结算火力、行动损耗（`Loss_action`）与附带战损。
5. **P5 市场出清**：`t % 5 == 4` 执行各地现货双边集合竞价与世界池撮合；`t % 10 == 9` 执行证券出清；成交货物进入 `next_available`。
6. **P6 生产、采掘、科研与施工**：仅使用未锁定的 `available`；出库仓容分两遍仲裁（**r9：制造产线优先于采掘线入仓**），产出写入 `next_available`（次 tick 可用，杜绝同拍级联）。
7. **P7 周期结算与缓冲合并**：消费、发薪、征税、分红、支持度、人口增长、宏观利率汇率与国力周期采集；最后把 `next_available` 合并进 `available`。
8. **P8 观测生成**：更新已验证科技解锁并按迷雾与权限过滤生成下一窗口 `obs`。

## 3. 世界规模与开局禀赋

- **空间尺度**：`512 × 512` L1 栅格 + `24 × 20` 战略分区（340–420 陆地 + 80–120 海洋，2–4 块大陆），8 个主要国家（每国 18–24 相连初始分区、5 座核心枢纽 `h0..h4`）、36–48 个中立城邦、220–280 座枢纽、1,100–1,500 条走廊边、24 个近地轨道槽位。
- **开局模板（集中于首都 `h0`）**：
  - 人口 200：194 平民（普工 144、技工 40、工程师 10）+ 6 军人（2 支驻防编队）；
  - 设施：27 座 S1（24 生产设施 + 3 住宅）+ 1 座 S2 基础药品线（`P033`，开局按 0.5 批运行）+ 9 座 G1 采掘点；
  - 仓容 `3,300`（基础 300 + 6 个 500 模块），住宅容量 `300`，3 辆未部署物流车；
  - 资金：国库 `100,000` 本币 + 居民池 `50,000` 本币（开局各币汇率 `e0 = 1`，冻结 `InitialCashBookRU = 150,000`）；
  - 民生单人每周期基准需求：`food 0.06`、`water 0.04`、`consumer_goods 0.03`、`medicine 0.01`、`medical_supplies 0.0025`、`electricity 0.02`。无命令开局药品库存约 160 周期耗尽，可用 `trade/pool_buy` 向世界池应急采购。

## 4. 精确国力 `V` 与五支柱公式

每周期国力总值：
```text
U = 0.25 * U_pop + 0.25 * U_ind + 0.20 * U_ctrl + 0.15 * U_tech + 0.15 * U_intl
```

1. **人口支柱 `U_pop`**：`100 * sum_r(psi * Pop_civ / 200 * Qlife * Qsec)`
   - 本土合法性 `psi ∈ [0.5, 1.0]`，占领区 `psi ∈ [0.15, 0.5]`（需驻控 40 周期逐步抬升）；
   - `Qlife` 依赖食品（合成食品占比超 30% 会折损）、民用品、药品/医疗用品、水电；`Qsec` 受战斗、封锁与污染扣减。
2. **工业支柱 `U_ind`**：`0.35 * (sum VA_eff - Loss_destroy - Loss_action + 0.05 * NetTransit + NFA_RU / 1000)`
   - 仅非采掘制造线计 `VA_eff`；
   - **过量囤货折损 `eta`**（逐国逐物品独立计算）：`chi = (I_physical_eta + SinkDebt) / max(1, mean_n(eligible_consumption))`（r9 永久豁免未耗尽的开局非回填禀赋余量），`chi <= 6` 时 `eta = 1`，否则线性降至 `0`（`chi >= 12` 归零）；
   - **`Loss_action` 严格自身损耗**：作战、行军、封锁、网攻、反卫星等实际耗材与算力按目录值计损（单事件最低 `0.001`），固定影子下任何无额外实益的敌对行动均使自身 `V` 严格下降；
   - **`NFA_RU` 历史成本账面**：基于冻结历史 RU 成本，单纯操控本币汇率无法虚增 NFA。
3. **控制支柱 `U_ctrl`**：`sum_connected(sigma_r) + 0.01 * Kinfra + 2 * min(8, N_sat) + 0.20 * min(MilCap, sum V_ready)`
   - 仅计与首都或有粮+通信设备的备份核心枢纽**补给连通**的受控区；
   - **r7/r9 `Kinfra` 细则**：公共仓库扩建模块按**实际占用率**计入（空扩仓不加分）；已建成非住宅空壳设施（全产线 `__idle__` 且未装机）仅按 `0.25` 计。
4. **科技支柱 `U_tech`**：`0.60 * sum_known(W_t * (0.15 + 0.85 * min(1, (ActiveScale + 0.5 * LicensedScale) / theta)))`
   - 仅解锁科技不落地只得 15% 分；必须通过对应配方、在线设施或有效算力达成 `ActiveScale >= theta` 才能拿满 100%。
5. **国际支柱 `U_intl`**：`0.08 * mean20(credit_weighted_exports) + 2.5 * Credit * aligned_cities + 0.05 * mean20(credit_weighted_aid)`
   - 出口与运输贡献仅在**不可逆真实末端消费**时确认，转仓、贸易倒手不刷分。

## 5. 四纪元轨迹、可持续系数 `Φ` 与百分制

- **可持续系数 `Φ ∈ [0.35, 1.0]`**：
  `Φ = max(0.35, 1 - d_maint - d_short - d_unrest - d_insolvency)`，扣项来自期末平均维护欠账、末 20 期食电缺口、受控人口橙红警比例、永久违约次数与末 40 期违约/脱锚事件。
- **有符号期末调整与总国力 `V`**：
  - `U_end_adj = max(U_end, 0) * Φ + min(U_end, 0) * (2 - Φ) - 10 * (1 - Φ)`
  - `V = 0.08 * U_I + 0.14 * U_II + 0.24 * U_III + 0.29 * U_IV + 0.25 * U_end_adj`
- **六维独立产权账本**：军事占领（清空守军且驻满 10 tick）只改变军事控制 `controller`（军管敌国资产产能上限 60%），不没收主权或第三方股权；强行国有化立扣国际信用 `-0.30`。
