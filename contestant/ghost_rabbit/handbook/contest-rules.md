# 比赛规则与常见踩坑清单 · 天翼幽灵兔

## 1. 公开状态优先校验（重要！）

本赛题故意规定：**所有落子合法性校验均在幽灵免疫弹开判定之前执行**。

- 即使你尝试把陷阱投放到兔子当前所在的格点 $r_{t-1}$（稍后会被弹开而不固化），如果该格点与 $F_{\le t-1}$ 构成 Local 3-AP（或与本轮另一枚落子重复、或超出 $[-10^5, 10^5]^2$、或不在 $\mathcal{H}_\omega$），评测器都会**直接判 `WA`**！
- 因此，选手程序只需根据自己维护的公开已固化集合 $F_{\le t-1}$ 与本轮落子 $A_t$ 做 `can_place_3ap_free` 检验，动作合法性与兔子隐藏位置 100% 无关。

## 2. 幽灵弹开的代币与集合结算

若第 $j$ 枚落子 $(a_j, b_j) = r_{t-1}$：
- `bounce_idx = j`；
- 代币照常扣除 $k_t \cdot Q'$（弹开的陷阱不退代币）；
- $(a_j, b_j)$ **不会**加入 $F_{\le t}$，因此下一轮（当兔子离开后）你依然可以在该格合法放陷阱；
- 若本轮 $k_t = 2$，另一枚未命中 $r_{t-1}$ 的落子仍然正常固化至 $F_{\le t}$；
- `bounce_idx > 0` 同时为你提供了珍贵的精确位置信息：$r_{t-1} = (a_j, b_j)$，可瞬间将整个信念集重置为单点后再向下一轮扩展！

## 3. 捕获信号与干净退出

- 收到 `1 0 0 0` 时，说明本轮放置生效后 $M_t = \emptyset$，兔子已无合法出路，本局已经成功捕获。
- 选手程序必须**立即结束交互循环并以返回码 `0` 退出**，不要在收到 `1 0 0 0` 后继续向 `stdout` 打印任何内容（否则会因违反交互协议判 `PE`）。
- 每一轮向 `stdout` 输出后务必显式刷新缓冲区（`std::cout << ... << '\n' << std::flush;` 或 `fflush(stdout)`），切勿仅写 `\n` 而不刷新导致双方互相等待直至 `TLE`。

## 4. 负坐标取模陷阱

C++ 中负整数 `% 3` 的结果可能为 `-1` 或 `-2`！计算 $\delta = (a + b) \bmod 3$ 时务必规范化到 $\{0, 1, 2\}$：

```cpp
inline int delta3(int a, int b) {
    int r = (a + b) % 3;
    return r < 0 ? r + 3 : r;
}
```

同样，在计算 `to_c3` 时，请确保 $(2a - b + \delta)$、$(2b - a + \delta)$、$(-a - b + \delta)$ 均为 3 的精确整数倍，切勿直接对负数做截断除法而不加 $\delta$。

## 5. 兔子越界与声呐边界

- 选手放置陷阱和声呐探测的坐标必须满足 $|a|, |b| \le 10^5$；
- 幽灵兔在无限蜂窝图上移动，**不受** $[-10^5, 10^5]^2$ 限制，不过受限于 $T_{\max} = 5\,000$ 与单步至多距 2，兔子距原点 $(1, 0)$ 的图距离永远不会超过 $10\,000$，远在声呐与布防坐标上限以内。

## 6. 双轨计分规则速查

- **单局得分**（设本局 `AC` 且最简速率 $q = P'/Q'$；非 `AC` 局计 `0`）：
  - 当 $\frac{1}{2} < q < 2$：$\operatorname{RawScore}(q) = 100 \cdot \dfrac{4Q' - 2P'}{2P' - Q'}$，$\operatorname{NormScore}(q) = 100 \cdot \dfrac{2Q' - P'}{P' + Q'} = 100 \cdot \dfrac{r}{r + 200}$；
  - 当 $q \le \frac{1}{2}$：$\operatorname{NormScore} = 100$，$\operatorname{RawScore} = \text{Singularity}\ (+\infty)$；
  - 当 $q \ge 2$：$\operatorname{NormScore} = 0$，$\operatorname{RawScore} = 0$。
- **正式评测汇总**：共 **`32` 局**（`4` 类互补隐藏对手家族 × `8` 个随机种子）：
  - **套题 0–100 总分（`score`）**：全部 `32` 局 `NormScore` 的等权算术平均；
  - **单题原分（`raw_score`）**：仅当 `32` 局全部 `AC` 时取最劣单局 `RawScore`（全通且全员 $q \le \frac{1}{2}$ 标记 `singularity = true`），任一局未 `AC` 则记 `0.00`。
