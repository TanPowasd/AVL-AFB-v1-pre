## 2. 一句话规则与正式计分标准

1v1 农场经营，配置 `episodeSteps = 720`（`30` 天 × `24` 小时；实际执行 `step = 0 .. 718` 共 `719` 步），**终局现金高者胜**。终局未卖出的库存、种子、建筑与动物价值均为 `0`。

- **正式计分（`scoring_v2`，满分 `100`）**：固定对阵 `3` 个隐藏参考对手 × `64` 个 OS 随机场景 × 交换座位（共 `384` 局），正常结束单局按 $s = 50 + 50\tanh\big((money_T - money_R) / 80096.26\big)$ 连续计分并等权平均（现金相同为 `50` 分）。
- **技术判负优先**：本方超时、异常超 `30` 次或加载失败判负时该局直接得 `0` 分；仅对手技术判负得 `100` 分；双方均判负各得 `0` 分。

## 3. 硬约束（违反 = 拒赛或判负）

- **压缩包结构与安全校验**：根目录必须包含 `main.py`；禁止路径穿越（`..`）、绝对路径、符号链接、加密条目与异常压缩比（`> 100×`）；压缩体积 `<= 64 MiB`，解压总大小 `<= 256 MiB`，条目数 `<= 2048`。

- **结构与参数约束**：`farmer`、`hands`、`market` 三键必填；**`hands` 长度必须严格等于当前工人数**（`len(obs["farms"][me]["hands"])`）；`market` 每步最多 10 条订单（超出截断）；未知 `op` 或参数类型错误（如 `["PICKUP", "WHEAT", "x"]`、`["PLANT", []]`、`["SELL", "WHEAT", float("inf")]`）均算结构错误，替换为全员 `PASS` 并计 `1` 次错误。
- **计时（正式口径）**：每步基础时限 **`1.0` 秒**；单步超出 `1.0` 秒的部分从**每局 `60.0` 秒超时池**（`observation["remainingOverageTime"]`）中扣除；池耗尽后任意一步超过 `1.0` 秒立即杀掉子进程并判超时负（该局 `0` 分）。
- **错误上限**：单局累计异常/结构错误超过 `30` 次立即判负（该局 `0` 分）。
- **公平性红线**：不得针对特定种子或对手写死逻辑；不得读取其他选手文件，不得与其他选手对战。公开陪练仅限 `passive` / `random` / `greedy` / `champion`（可自身镜像自搏）。
- **工作区边界**：只能访问当前工作区（及综合工作区顶层的 `../submissions/kaggriculture.zip`）；自测成绩、调试 trace、回放与日志只保存在 `results/`、`replays/`、`logs/`。自测工具会拒绝外部路径（含软链接越界）、非公开陪练与 `--unrestricted`；禁止修改 `config/workspace.json`、规则引擎、裁判、陪练脚本与 `config/format.json`。

## 5. 六个必踩的坑（省你半天）

1. **雇工出生点可能落在未解锁格（`LOCKED`）**：谷仓相邻 4 格中 `(5,4)`、`(4,5)`、`(5,5)` 开局未解锁；单位可以走进或出生在 `LOCKED` 格（仍可执行 `DROP`/`PICKUP`/入库 `PLACE`），但不能耕作或建造，必须写移回已解锁区的逻辑；
2. **新种作物当天必须浇水，且非持续作物初产 `yield_units = 1`**：刚种下时 `consecutive_unwatered = 1`，当天不浇水日终直接枯成 `WEED`；另外非持续作物种下即有 `yield_units = 1`，但未达 `first_yield_day` 时 `HARVEST` 会被静默忽略，判断收割必须同时检查天龄；
3. **第 29 天没有日终结算**：`step = 719` 不执行，第 29 天背包物品**不会自动入库**；必须在谷仓相邻格手动 `DROP` 或 `PLACE` 后再 `SELL`（单位行动先于市场订单，最晚可在 `step 718` 同一步完成 `DROP` 与 `SELL`）；
4. **雇工每日自动解散且雇佣费当日斐波那契递增**：当日第 `k` 次雇佣费 `fib(k) = 1, 1, 2, 3, 5, 8, 13, 21, ...`，日终（第 0..28 天）自动把背包转入谷仓、主农夫重置回 `(4, 4)`、解散所有雇工并清零 `hires_today`；单日狂雇会迅速烧光现金；
5. **卖货砸价与同槽锁步竞争**：市场按槽位逐件锁步成交，同品卖越多价格越低，双方同卖会互相压价；结合城镇商店消耗错峰/分散出货收益更高；
6. **谷仓容量上限 `100`**：`DROP` 把整个背包倒入谷仓，超出 `100` 的部分**直接销毁**；若需避免丢货，可在谷仓旁改用 `PLACE <ITEM> <n>`（装不下的部分留在背包）。

## 2. 观测（每步给你的只读快照）

`observation` 同时支持属性访问 `obs.day` 与字典访问 `obs["day"]`（裁判保证两种都可用）。

| 字段 | 含义 |
|---|---|
| `step` / `day` / `hour` | 全局步（`0..718`，共 `719` 步） / 天（`0..29`） / 小时（`0..23`） |
| `player` | 你的座位号 `0` 或 `1` |
| `farms[2]` | 双方公开农场：`money`、`tiles[10][10]`（按 `tiles[y][x]` 索引）、`farmer: [x, y]`、`hands: [[x, y], ...]`、`unlocked_quadrants`、`hires_today` |
| `market` | `inventory`（9 种商品当前库存）、`prices`（9 种商品当前单价） |
| `town` | `unlocked_shops`（已解锁商店名称列表，可能含重复商店） |
| `private` | 仅己方可见：`shed`（仓库物品/动物数量）、`seeds`（5 种作物种子数量，不占仓库容量）、`inventories`（随身背包列表，无容量上限） |
| `remainingOverageTime` | 剩余超时池秒数（初始 `60.0`） |

- `tiles[y][x]` 单元取值：`None`（空地）、`"LOCKED"`（未解锁）、`{"kind": "WEED"}`、`{"kind": "PLANT", "crop", "planted_day", "watered_today", "consecutive_unwatered", "yield_units", "max_lifespan_step", "fertilized_until_day"}`、`{"kind": "COOP"|"PASTURE", ...}`（若含动物则额外带 `"animal", "placed_day", "yield_units", "consecutive_unfed", "fed_today", "cared_today", "fertilizer_available", "pending_care_bonus"`）。
- `private["inventories"]` 与单位一一对应：`inventories[0]` 是主农夫，`inventories[k]` 对应 `hands[k - 1]`。

## 3. 动作（每步返回）

```python
{
    "farmer": [op, *args],          # 主农夫动作
    "hands":  [[op, *args], ...],   # 长度必须严格等于当前 len(farms[player]["hands"])
    "market": [[op, *args], ...],   # 最多 10 条订单（超出截断）
}
```

- **单位动作 `op`**：`NORTH` / `SOUTH` / `EAST` / `WEST`、`PASS`、`PLANT <CROP>`、`WATER`、`HARVEST`、`DIG`、`FERTILIZE`、`BUILD_COOP`、`BUILD_PASTURE`、`PLACE <ITEM> [n]`、`PICKUP <ITEM> [n]`、`DROP`、`FEED`、`COLLECT_FERTILIZER`、`CARE`。
- **市场订单 `op`**：`BUY_SEED <CROP> <n>`、`BUY_PRODUCT <WHEAT|FERTILIZER> <n>`、`BUY_ANIMAL <ANIMAL> <n>`、`SELL <ITEM> <n>`、`HIRE`、`BUY_LAND`。
- 方向：`NORTH = (0, -1)`、`SOUTH = (0, +1)`、`EAST = (+1, 0)`、`WEST = (-1, 0)`。
- 参数类型合法但当前无法执行的子动作（如越界移动、对空地收割、钱不够买地）会被引擎**静默忽略**，不计错误；但参数类型错误会触发结构错误并扣错误预算。

## 4. 关键机制（精确数值见 `handbook/game-facts.md`）

- **结算顺序**：每步严格按 `单位行动 → 市场订单 → 城镇消耗 → 过熟作物衰减 → 日终结算（仅每日最后一步 (step + 1) % 24 == 0）` 执行。
- **种植与浇水**：
  - 本步全员计划 `PLANT <CROP>` 总数若超过 `private["seeds"][crop]`，本步针对该作物的**全部** `PLANT` 动作统一失效变 `PASS`；
  - 刚种下的作物 `consecutive_unwatered = 1`，**种植当天必须浇水**，否则当日日终直接枯萎变 `WEED`；浇过水后需连续 2 天不浇才会枯死；
  - `WATER` 每天每株只生效一次；非持续作物种下即有 `yield_units = 1`，但未达到 `first_yield_day` 前 `HARVEST` 会被忽略。
- **仓库与背包**：
  - 收割的农产品与动物产品进入随身背包；`SELL` 只卖 `shed` 里的商品；`shed` 总容量 `100`（所有农产品与未放置动物共享）；
  - 谷仓相邻格为棋盘中心 4 格 `(4, 4)`、`(5, 4)`、`(4, 5)`、`(5, 5)`；`DROP`、`PICKUP` 及向仓库存货的 `PLACE` 仅在这 4 格生效（即使格子处于 `LOCKED` 状态也能存取）；
  - `DROP` 清空整个背包入库，**超出 100 容量的部分直接销毁**；`PLACE <ITEM> [n]` 入库受剩余容量限制，放不下的保留在背包里。
- **日终结算与第 29 天清仓**：
  - 第 `0..28` 天日终（`hour == 23`）会自动把所有单位背包转入 `shed`（溢出销毁）、主农夫重置回 `(4, 4)`、**所有当日雇工自动解散**并清零 `hires_today`；
  - **第 `29` 天没有日终结算**（引擎在 `step = 718` 后结束，`step = 719` 不执行），第 29 天背包里的货不会自动入库！必须手动走到谷仓相邻格执行 `DROP` 或 `PLACE` 后再 `SELL`（因单位行动先于市场订单，最晚可在 `step 718` 同一步完成 `DROP` 和 `SELL`）；
  - 终局只看 `money`：未卖出的库存、种子、建筑与动物价值全部为 `0`。
- **雇佣与买地**：
  - `HIRE` 当日第 `k` 次费用为斐波那契数 `fib(k)`（`1, 1, 2, 3, 5, 8, 13, 21, ...`），每日重置；新雇工在当步市场阶段出生在谷仓相邻 4 格中人数最少的第一格，下一步开始行动；
  - `BUY_LAND` 依次解锁 `NE(1000) → SW(2000) → SE(4000)`；初始只有 `NW` 解锁。单位可走入 `LOCKED` 格但不能在其上耕作或建造。
- **市场与城镇**：
  - 卖货压低市场价（地板价 `1`），买货（`WHEAT`/`FERTILIZER`）推高市场价；双方同槽位订单按逐件锁步成交，同卖同品会互相砸价；
  - 城镇商店每 4 步消耗需求品（单品店消耗 2 件），镇中心每 24 步消耗除 `FERTILIZER` 外的其余 8 种商品各 1 件，推动价格回升。

# 游戏事实卡（全部核对自权威规则源码 `engine/rules.py`）

## 对局参数

- `episodeSteps = 720`（`30` 天 × `24` 小时；实际调用 `act` 共 `719` 次：`step = 0 .. 718`，`day = step // 24`，`hour = step % 24`）
- `boardSize = 10`（坐标 `0 <= x < 10, 0 <= y < 10`，`tiles[y][x]`），`turnsPerDay = 24`
- `startingMoney = 3000.0`，`maxMarketOrdersPerTurn = 10`，`shedCapacity = 100`，`weedSpawnChance = 0.005`
- 终局得分 = `step = 718` 结算完毕后各农场的 `money`（未售库存、种子、建筑与动物均不折算现金）。**第 `29` 天没有日终结算**（`step = 719` 不执行）。

## 作物 `CROPS`（`seed` = 固定买种价）

| 作物 | 种价 | 首收天 `first_yield_day` | 最高产天 `max_yield_day` | 间隔 `interval` | 持续产 `ongoing` | 产量上限 `max_yield` |
|---|---:|---:|---:|---:|:---:|---:|
| `WHEAT` | 10 | 2 | 4 | 0 | 否 | 6 |
| `CARROT` | 20 | 2 | 3 | 0 | 否 | 4 |
| `TOMATO` | 50 | 8 | 8 | 1 | 是 | 4 |
| `STRAWBERRY` | 100 | 10 | 10 | 2 | 是 | 4 |
| `MELON` | 80 | 10 | 12 | 0 | 否 | 6 |

- **批量种植检查**：若同一步内全员提交的 `PLANT <CROP>` 次数大于 `private["seeds"][crop]`，本步针对该作物的**全部** `PLANT` 动作统一变 `PASS`。
- **初始状态**：种下时 `planted_day = day`、`watered_today = False`、`consecutive_unwatered = 1`、`fertilized_until_day = -1`。**种下当天必须浇水，否则当日日终 `consecutive_unwatered` 达到 `2` 直接变 `WEED`。** 浇过水后归 `0`，此后需连续 2 天不浇水才枯萎。
- **非持续作物（`WHEAT` / `CARROT` / `MELON`）**：初始 `yield_units = 1`，`max_lifespan_step = (day + max_yield_day + 1) * 24`。在天龄 `age = day - planted_day` 满足 `(max_yield_day + 1) // 2 <= age <= max_yield_day` 的当天首次 `WATER` 时，`yield_units` 增加 `2`（若 `fertilized_until_day >= day`）或 `1`（封顶 `max_yield`）。`HARVEST` 需 `age >= first_yield_day` 且 `yield_units > 0`，收割后格子变 `None`。
- **持续作物（`TOMATO` / `STRAWBERRY`）**：初始 `yield_units = 0`，`max_lifespan_step = -1`。在日终结算（记 `next_day = day + 1`、`d = next_day - planted_day - first_yield_day`）时，若 `d >= 0`、`d % interval == 0` 且累计产果次数 `c = d // interval + 1 <= max_yield`，则 `yield_units` 增加 `2`（若当日浇过水且 `fertilized_until_day >= day`）或 `1`（封顶 `max_yield`）；当 `c == max_yield` 时设 `max_lifespan_step = (next_day + 1) * 24`。`HARVEST` 将 `yield_units` 收入背包并清零，植株保留。
- **过熟衰减**：对 `max_lifespan_step >= 0` 的作物，当 `step >= max_lifespan_step` 且 `(step - max_lifespan_step) % 2 == 0` 时 `yield_units -= 1`；减至 `<= 0` 变 `{"kind": "WEED"}`。
- **施肥 `FERTILIZE`**：消耗背包 `1` 个 `FERTILIZER`，令 `fertilized_until_day = max(fertilized_until_day, day + 2)`。

## 动物 `ANIMALS`

| 动物 | 购买价 | 所需建筑 | 首产天 `first_yield_day` | 间隔 `interval` | 存量上限 `max_held` | 产出商品 |
|---|---:|:---:|---:|---:|---:|:---:|
| `GOOSE` | 300 | `COOP` | 4 | 1 | 4 | `EGG` |
| `COW` | 400 | `PASTURE` | 8 | 2 | 6 | `MILK` |
| `SHEEP` | 500 | `PASTURE` | 6 | 3 | 6 | `WOOL` |

- `BUILD_COOP` 与 `BUILD_PASTURE` 在空地 `None` 上免费建造。
- `BUY_ANIMAL` 购得动物进入 `shed`（占 `1` 格容量），需在谷仓旁 `PICKUP <ANIMAL> 1` 拿到背包，走到空建筑格执行 `PLACE <ANIMAL>` 安置。
- 动物产品用 `HARVEST` 站在动物格上收取（全部 `yield_units` 入背包并清零）。
- `FEED` 消耗背包 `1` 个 `WHEAT`（每只每天限一次）；`CARE` 不耗物（每只每天限一次）。
- **动物日终结算**：未喂则 `consecutive_unfed += 1`，达到 `2` 时动物消失、退回空建筑；存活时若 `(next_day - placed_day - first_yield_day) >= 0` 且能被 `interval` 整除，则产出 `1 + (pending_care_bonus if fed_today else 0)`（封顶 `max_held`）并清零 `pending_care_bonus`；随后若当日 `cared_today and fed_today`，下一轮 `pending_care_bonus += 1`；最后所有存活的动物均置 `fertilizer_available = True`、`fed_today = False`、`cared_today = False`。
- `COLLECT_FERTILIZER` 在 `fertilizer_available == True` 的动物格收取 `1` 个 `FERTILIZER` 到背包（安置当天初始为 `False`，次日起每日可收 1 次）。

## 市场定价 `MARKET_PARAMS`

9 种商品：`WHEAT, CARROT, TOMATO, STRAWBERRY, MELON, EGG, MILK, WOOL, FERTILIZER`。
初始库存均为 `I0 = 10000`（库存无下限，可低于 `0`），初始价等于 `base`，地板价 `PRICE_FLOOR = 1`（`round` 为 Python 四舍六入五成双）。

- 当 `I < I0`：`price = max(1, round(base + amp_below * shape(below_func, I0 - I, T)))`，`amp_below = below_target * base / shape(below_func, T, T)`
- 当 `I >= I0`：`price = max(1, round(base - amp_above * shape(above_func, I - I0, T)))`，`amp_above = above_target * base / shape(above_func, T, T)`
- `shape(func, x, T)`：`linear = x`，`sq = x^2`，`sqrt = sqrt(x)`，`log = ln(1 + x)`，`hinge = (x / T) + 8.0 * max(0, x / T - 1)^2`。

| 商品 | `base` | `T` | `below_func` | `below_target` | `above_func` | `above_target` |
|---|---:|---:|:---:|---:|:---:|---:|
| `WHEAT` | 25 | 400 | `sqrt` | 0.8 | `log` | 0.2 |
| `CARROT` | 35 | 450 | `hinge` | 1.0 | `sqrt` | 0.7 |
| `TOMATO` | 60 | 200 | `hinge` | 0.4 | `sqrt` | 0.6 |
| `STRAWBERRY` | 120 | 100 | `sqrt` | 0.7 | `linear` | 1.6 |
| `MELON` | 250 | 300 | `log` | 0.2 | `sq` | 3.6 |
| `EGG` | 50 | 332 | `hinge` | 0.4 | `log` | 0.2 |
| `MILK` | 160 | 122 | `sqrt` | 0.6 | `linear` | 1.6 |
| `WOOL` | 200 | 105 | `log` | 0.2 | `sq` | 3.2 |
| `FERTILIZER` | 100 | 200 | `linear` | 0.4 | `linear` | 0.4 |

- `SELL <ITEM> <n>`：仅卖 `shed` 内 9 种商品；按当前报价得钱，仅当成交价 `> 1` 时市场库存 `+1`（地板价 `1` 时库存不再增加）。
- `BUY_PRODUCT <ITEM> <n>`：仅限 `WHEAT` / `FERTILIZER`，报价按 `market_price(item, I - 1)`，存入 `shed`（受 `100` 容量限制），市场库存 `-1`。
- `BUY_SEED <CROP> <n>` 与 `BUY_ANIMAL <ANIMAL> <n>`：按固定表价成交，不影响市场库存（种子进 `seeds`，动物进 `shed` 占容量）。
- **逐件同步锁步（per-unit lockstep）**：按订单槽位 `i = 0 .. 9` 推进；`HIRE`/`BUY_LAND` 立即执行，其余买卖订单逐件同步报价（双方基于同一当前库存同时报价）、逐件扣库存成交，单槽最多循环 `99999` 轮，随后刷新公开市场价。

## 城镇商店 `SHOPS`

- `BAKERY`: `["EGG", "WHEAT"]`
- `PIZZA_SHOP`: `["MILK", "TOMATO", "WHEAT"]`
- `BRUNCH_SPOT`: `["EGG", "WHEAT", "STRAWBERRY"]`
- `YARN_STORE`: `["WOOL"]`（单品店，每次消耗 2 件）
- `ICE_CREAM_SHOP`: `["STRAWBERRY", "MILK", "WHEAT"]`
- `PET_CAFE`: `["CARROT"]`（单品店，每次消耗 2 件）
- `SMOOTHIE_SHOP`: `["STRAWBERRY", "MILK"]`
- `FARMERS_MARKET`: `["WHEAT", "CARROT", "TOMATO", "STRAWBERRY"]`

- 每 `4` 步（`step % 4 == 0`）：遍历每家已解锁商店消耗库存（单品店减 `2`，其余每种减 `1`）。
- 每 `24` 步（`step % 24 == 0`）：镇中心消耗除 `FERTILIZER` 外的其余 `8` 种商品库存各 `1` 件。
- 解锁商店：日终若 `(day + 1) % 3 == 0` 且已解锁商店总数 `< 8`，使用日结随机流 `rng = random.Random(seed * 1000003 ^ day)`（在双方杂草抽签之后）从 8 类商店中等概率**可重复**随机解锁 1 家。

## 雇佣、土地与日终重置

- **`HIRE`**：当日第 `k` 次（`k = hires_today >= 0`）费用为 `fib(k)`：`1, 1, 2, 3, 5, 8, 13, 21, 34, ...`；新雇工在当步市场阶段出生在谷仓相邻 4 格 `[(4,4), (5,4), (4,5), (5,5)]` 中当前本方人数最少的第一格，下一步开始行动。
- **`BUY_LAND`**：按 `NE (1000) → SW (2000) → SE (4000)` 顺序解锁象限，将象限内 `"LOCKED"` 格变为 `None`。
- **日终重置（第 `0..28` 天 `step % 24 == 23`）**：
  1. 初始化日结 `rng = random.Random(seed * 1000003 ^ day)`，按座位 `0 → 1` 依次执行：作物日结 → 动物日结 → 空地杂草生长（每空地 `None` 以 `0.005` 概率变 `WEED`，与官方 Kaggle 环境一致）；
  2. 所有单位背包按顺序自动转入 `shed`（超出 `100` 容量的部分销毁）；
  3. 主农夫重置回 `(4, 4)`，**所有雇工解散**（`hands = []`，`hires_today = 0`，`inventories = [{}]`）；
  4. 按需使用同一日结 `rng` 解锁新商店。

## 空间、单位与已实测事实

- **谷仓相邻格**：`(4, 4)`、`(5, 4)`、`(4, 5)`、`(5, 5)`。`DROP`（溢出销毁）、`PICKUP` 及向仓库存货的 `PLACE`（溢出留在背包）在这 4 格均生效，即便该格处于 `"LOCKED"` 状态。
- 移动方向：`NORTH = (0, -1)`、`SOUTH = (0, +1)`、`EAST = (+1, 0)`、`WEST = (-1, 0)`。允许走进 `"LOCKED"` 格，但不能在其上耕作或建造。
- `DIG` 清除脚下作物、杂草或无动物的空建筑（有动物的建筑不能 `DIG`）。
- 实测要点：
  - 单押 `MELON` 极易把自身市场价砸到地板价 `1`；高需求品（如多店需求的 `STRAWBERRY` / `MILK` / `WHEAT`）常随城镇消耗拉升；
  - 单日无节制 `HIRE`（如 16+ 次）会因斐波那契费用迅速吃光现金，须设雇佣护栏；
  - 终局未售库存价值为 `0`，末期（尤其第 29 天，因无日终自动入库）必须主动 `DROP`/`PLACE` 并清仓卖出。

# -*- coding: utf-8 -*-
"""多文件包示例子模块：演示如何拆分策略逻辑并读取包内只读配置参数。"""
from __future__ import annotations


class SimplePlanner:
    def __init__(self, params: dict) -> None:
        self.default_crop = str(params.get("default_crop", "WHEAT"))
        self.min_seed_stock = int(params.get("min_seed_stock", 2))
        self.seed_buy_batch = int(params.get("seed_buy_batch", 2))

    def step(self, obs: dict) -> dict:
        me = obs["player"]
        farm = obs["farms"][me]
        priv = obs["private"]
        hands = farm["hands"]
        fx, fy = farm["farmer"]
        tile = farm["tiles"][fy][fx]
        seeds = priv.get("seeds", {})
        shed = priv.get("shed", {})

        farmer_act: list = ["PASS"]
        market_orders: list = []

        # 简单闭环示例：买种子 -> 在脚下种植/浇水/收获 -> 回谷仓交货并出售

            market_orders.append(["SELL", self.default_crop, shed[self.default_crop]])

        carry = priv.get("inventories", [{}])[0] if priv.get("inventories") else {}
        if carry and (fx, fy) in ((4, 4), (5, 4), (4, 5), (5, 5)):
            farmer_act = ["DROP"]
        elif tile is None and seeds.get(self.default_crop, 0) > 0:
            farmer_act = ["PLANT", self.default_crop]
        elif isinstance(tile, dict) and tile.get("kind") == "PLANT":
            if tile.get("yield_units", 0) > 0 and obs["day"] - tile.get("planted_day", 0) >= 2:
                farmer_act = ["HARVEST"]
            elif not tile.get("watered_today"):
                farmer_act = ["WATER"]
        elif isinstance(tile, dict) and tile.get("kind") == "WEED":
            farmer_act = ["DIG"]

        return {
            "farmer": farmer_act,
            "hands": [["PASS"] for _ in hands],
            "market": market_orders[:10],
        }

def _shape(func, x, T=None):
    x = max(0.0, x)
    if func == 'linear':
        return x
    if func == 'sq':
        return x * x
    if func == 'sqrt':
        return math.sqrt(x)
    if func == 'log':
        return math.log(1.0 + x)
    if func == 'log10':
        return math.log10(1.0 + x)
    if func == 'hinge':
        if not T or T <= 0:
            return x
        u = x / T
        return u + HINGE_GAIN * max(0.0, u - 1.0) ** 2
    return x

def _spawn_hand(farm, board_size):

    occupants = {tile: 0 for tile in _shed_access_tiles(board_size)}

    for pos in all_pos:

            occupants[pos] += 1
    best = sorted(occupants.items(), key=lambda kv: (kv[1], _shed_access_tiles(board_size).index(kv[0])))

def _process_market(state, env):
    """Per-unit lockstep: at each step, quote both players' current-unit prices, then commit both."""
    obs0 = state[0].observation
    market = obs0.market
    farms = obs0.farms
    privates = [s.observation.private for s in state]
    board_size = int(get(env.configuration, 'boardSize', 10))
    max_orders = max(1, int(get(env.configuration, 'maxMarketOrdersPerTurn', 10)))
    hire_mult = int(get(env.configuration, 'farmHandCostMult', FARM_HAND_COST_MULT))
    shed_capacity = int(get(env.configuration, 'shedCapacity', 100))
    queues = []
    for s in state:
        action = s.action if isinstance(s.action, dict) else {}
        m = action.get('market', []) if isinstance(action, dict) else []
        q = list(m) if isinstance(m, list) else []
        queues.append(q[:max_orders])
    max_len = max((len(q) for q in queues), default=0)
    for i in range(max_len):
        order_states = []
        for player_id, q in enumerate(queues):
            ostate = None
            if i < len(q):
                ostate = _parse_order(q[i])
            order_states.append(ostate)
        for player_id, ostate in enumerate(order_states):
            if ostate is None:
                continue
            op = ostate['type']
            if op == 'HIRE':
                _do_hire(farms[player_id], privates[player_id], board_size, hire_mult)
                order_states[player_id] = None
            elif op == 'BUY_LAND':
                _do_buy_land(farms[player_id], board_size)
                order_states[player_id] = None
        idx_esc = 0
        while True:
            idx_esc += 1
            if idx_esc >= 100000:
                print('WARNING: kaggriculture market loop exceeded 100k iterations; aborting')
                break
            quoted = [None, None]
            for player_id, ostate in enumerate(order_states):
                if ostate is None or ostate['remaining'] <= 0:
                    continue
                op = ostate['type']
                item = ostate['item']
                if op == 'SELL' and item in PRODUCTS:
                    quoted[player_id] = ('SELL', item, market_price(item, market['inventory'][item], market.get('params')), ostate)
                elif op == 'BUY_PRODUCT' and item in ('WHEAT', 'FERTILIZER'):
                    quoted[player_id] = ('BUY_PRODUCT', item, market_price(item, market['inventory'][item] - 1, market.get('params')), ostate)
                elif op == 'BUY_SEED' and item in CROPS:
                    quoted[player_id] = ('BUY_SEED', item, CROPS[item]['seed'], ostate)
                elif op == 'BUY_ANIMAL' and item in ANIMALS:
                    quoted[player_id] = ('BUY_ANIMAL', item, ANIMALS[item]['cost'], ostate)
                else:
                    order_states[player_id] = None
            if all((q is None for q in quoted)):
                break
            committed_any = False
            for player_id, q in enumerate(quoted):
                if q is None:
                    continue
                op, item, price, ostate = q
                ok = _commit_unit(op, item, price, farms[player_id], privates[player_id], market, shed_capacity)
                if ok:
                    ostate['remaining'] -= 1
                    committed_any = True
                else:
                    order_states[player_id] = None
            if not committed_any:
                break
        _refresh_prices(market)

def _parse_order(order):
    if not isinstance(order, list) or not order:
        return None
    op = order[0]
    if op == 'HIRE':
        return {'type': 'HIRE'}
    if op == 'BUY_LAND':
        return {'type': 'BUY_LAND'}
    if op in ('BUY_SEED', 'BUY_PRODUCT', 'BUY_ANIMAL', 'SELL'):
        if len(order) < 3:
            return None
        try:
            n = int(order[2])
        except (TypeError, ValueError):
            return None
        if n <= 0:
            return None
        return {'type': op, 'item': order[1], 'remaining': n}
    return None

def _commit_unit(op, item, price, farm, private, market, shed_capacity=100):
    if op == 'SELL':
        if private['shed'].get(item, 0) <= 0:
            return False
        private['shed'][item] -= 1
        farm['money'] += price
        if price > 1:
            market['inventory'][item] += 1
        return True
    if op == 'BUY_PRODUCT':
        if farm['money'] < price:
            return False
        if sum(private['shed'].values()) >= shed_capacity:
            return False
        farm['money'] -= price
        private['shed'][item] = private['shed'].get(item, 0) + 1
        market['inventory'][item] -= 1
        return True
    if op == 'BUY_SEED':
        if farm['money'] < price:
            return False
        farm['money'] -= price
        private['seeds'][item] = private['seeds'].get(item, 0) + 1
        return True
    if op == 'BUY_ANIMAL':
        if farm['money'] < price:
            return False
        if sum(private['shed'].values()) >= shed_capacity:
            return False
        farm['money'] -= price
        private['shed'][item] = private['shed'].get(item, 0) + 1
        return True
    return False

def _fib(n):
    """Indexed so _fib(0)=1, _fib(1)=1, _fib(2)=2, _fib(3)=3, _fib(4)=5..."""
    a, b = (1, 1)
    for _ in range(n):
        a, b = (b, a + b)
    return a

def _hire_cost(n_already_today, mult=FARM_HAND_COST_MULT):
    return mult * _fib(n_already_today)

def _do_hire(farm, private, board_size, mult=FARM_HAND_COST_MULT):
    cost = _hire_cost(farm['hires_today'], mult)
    if farm['money'] < cost:
        return
    farm['money'] -= cost
    farm['hires_today'] += 1
    farm['hands'].append(_spawn_hand(farm, board_size))
    private['inventories'].append({})

def _do_buy_land(farm, board_size):
    n_unlocked_extra = len(farm['unlocked_quadrants']) - 1
    if n_unlocked_extra >= len(LAND_ORDER):
        return
    cost = LAND_PRICES[n_unlocked_extra]
    if farm['money'] < cost:
        return
    farm['money'] -= cost
    quadrant = LAND_ORDER[n_unlocked_extra]
    farm['unlocked_quadrants'].append(quadrant)
    for y in range(board_size):
        for x in range(board_size):
            if _quadrant_of(x, y, board_size) == quadrant and farm['tiles'][y][x] == 'LOCKED':
                farm['tiles'][y][x] = None

def _town_consume(env, state, step):
    obs0 = state[0].observation
    market = obs0.market
    town = obs0.town
    cfg = env.configuration
    shop_interval = max(1, int(get(cfg, 'townShopSellInterval', 4)))
    center_interval = max(1, int(get(cfg, 'townCenterSellInterval', 24)))
    if step % shop_interval == 0:
        for shop_name in town.get('unlocked_shops', []):
            products = SHOPS[shop_name]
            multiplier = 2 if len(products) == 1 else 1
            for item in products:
                market['inventory'][item] -= multiplier
    if step % center_interval == 0:
        for item in TOWN_CENTER_PRODUCTS:
            market['inventory'][item] -= 1
    _refresh_prices(market)

def _decay_plants(farm, step):
    board_size = len(farm['tiles'])
    for y in range(board_size):
        for x in range(board_size):
            tile = farm['tiles'][y][x]
            if not isinstance(tile, dict) or tile.get('kind') != 'PLANT':
                continue
            mls = tile['max_lifespan_step']
            if mls < 0 or step < mls:
                continue
            if (step - mls) % 2 != 0:
                continue
            tile['yield_units'] -= 1
            if tile['yield_units'] <= 0:
                farm['tiles'][y][x] = {'kind': 'WEED'}

def _daily_refresh_plants(farm, current_day, turns_per_day):
    board_size = len(farm['tiles'])
    next_day = current_day + 1
    for y in range(board_size):
        for x in range(board_size):
            tile = farm['tiles'][y][x]
            if not isinstance(tile, dict) or tile.get('kind') != 'PLANT':
                continue
            was_watered = tile['watered_today']
            if was_watered:
                tile['consecutive_unwatered'] = 0
            else:
                tile['consecutive_unwatered'] += 1
            tile['watered_today'] = False
            if tile['consecutive_unwatered'] >= 2:
                farm['tiles'][y][x] = {'kind': 'WEED'}
                continue
            cd = CROPS[tile['crop']]
            if not cd['ongoing']:
                continue
            days_since_first = next_day - tile['planted_day'] - cd['first_yield_day']
            if days_since_first < 0:
                continue
            interval = cd['interval']
            if days_since_first % interval != 0:
                continue
            production_count = days_since_first // interval + 1
            if production_count > cd['max_yield']:
                continue
            fertilized = was_watered and tile.get('fertilized_until_day', -1) >= current_day
            tile['yield_units'] = min(cd['max_yield'], tile['yield_units'] + (2 if fertilized else 1))
            if production_count == cd['max_yield']:
                tile['max_lifespan_step'] = (next_day + 1) * turns_per_day

def _daily_refresh_animals(farm, day):
    board_size = len(farm['tiles'])
    next_day = day + 1
    for y in range(board_size):
        for x in range(board_size):
            tile = farm['tiles'][y][x]
            if not (isinstance(tile, dict) and 'animal' in tile):
                continue
            if tile['fed_today']:
                tile['consecutive_unfed'] = 0
            else:
                tile['consecutive_unfed'] += 1
            if tile['consecutive_unfed'] >= 2:
                farm['tiles'][y][x] = {'kind': ANIMALS[tile['animal']]['structure']}
                continue
            a = ANIMALS[tile['animal']]
            days_since_first = next_day - tile['placed_day'] - a['first_yield_day']
            if days_since_first >= 0 and days_since_first % a['interval'] == 0:
                base = 1
                bonus = tile.pop('pending_care_bonus', 0) if tile['fed_today'] else 0
                tile['yield_units'] = min(a['max_held'], tile['yield_units'] + base + bonus)
                tile['pending_care_bonus'] = 0
            if tile['cared_today'] and tile['fed_today']:
                tile['pending_care_bonus'] = tile.get('pending_care_bonus', 0) + 1
            tile['fertilizer_available'] = True
            tile['fed_today'] = False
            tile['cared_today'] = False

def _spawn_weeds(farm, board_size, weed_chance, rng):
    for y in range(board_size):
        for x in range(board_size):
            if farm['tiles'][y][x] is None and rng.random() < weed_chance:
                farm['tiles'][y][x] = {'kind': 'WEED'}

def _drop_inventories_to_shed(private, capacity):
    """Drop every per-farmer inventory into the shed up to `capacity`; overflow is discarded.
    Seeds are tracked separately in private["seeds"] and don't pass through the shed."""
    shed = private['shed']
    for inv in private['inventories']:
        for item, n in list(inv.items()):
            if n <= 0:
                del inv[item]
                continue
            current = sum((v for k, v in shed.items()))
            room = max(0, capacity - current)
            take = min(n, room)
            if take > 0:
                shed[item] = shed.get(item, 0) + take
            del inv[item]

def _end_of_day(state, env, day):
    obs0 = state[0].observation
    cfg = env.configuration
    board_size = int(get(cfg, 'boardSize', 10))
    turns_per_day = max(1, int(get(cfg, 'turnsPerDay', 24)))
    weed_chance = float(get(cfg, 'weedSpawnChance', 0.005))
    shed_cap = int(get(cfg, 'shedCapacity', 100))
    shop_interval = max(1, int(get(cfg, 'townShopUnlockInterval', 3)))
    seed = env.info.get('seed', 0)
    rng = random.Random(seed * 1000003 ^ day)
    for player_id, farm in enumerate(obs0.farms):
        private = state[player_id].observation.private
        _daily_refresh_plants(farm, day, turns_per_day)
        _daily_refresh_animals(farm, day)
        _spawn_weeds(farm, board_size, weed_chance, rng)
        _drop_inventories_to_shed(private, shed_cap)
        farm['farmer'] = list(_default_spawn(board_size))
        farm['hands'] = []
        farm['hires_today'] = 0
        private['inventories'] = [{}]
    next_day = day + 1
    town = obs0.town
    if next_day > 0 and next_day % shop_interval == 0:
        if len(town['unlocked_shops']) < MAX_SHOP_INSTANCES:
            town['unlocked_shops'].append(rng.choice(sorted(SHOPS)))

def interpreter(state, env):
    num_agents = len(state)
    obs0 = state[0].observation
    if not hasattr(obs0, 'farms') or not obs0.farms:
        _initialize(state, env)
        return state
    if env.done:
        return state
    cfg = env.configuration
    turns_per_day = max(1, int(get(cfg, 'turnsPerDay', 24)))
    board_size = int(get(cfg, 'boardSize', 10))
    shed_capacity = int(get(cfg, 'shedCapacity', 100))
    step = get(obs0, 'step', 0)
    day = step // turns_per_day
    for i, s in enumerate(state):
        action = s.action if isinstance(s.action, dict) else {}
        farmer_action = action.get('farmer', ['PASS']) if isinstance(action, dict) else ['PASS']
        hands_actions = action.get('hands', []) if isinstance(action, dict) else []
        if not isinstance(hands_actions, list):
            hands_actions = []
        unit_actions = [farmer_action, *hands_actions]
        plant_demand = {}
        for a in unit_actions:
            if isinstance(a, list) and len(a) >= 2 and (a[0] == 'PLANT'):
                plant_demand[a[1]] = plant_demand.get(a[1], 0) + 1
        seeds = s.observation.private.get('seeds', {}) if hasattr(s.observation.private, 'get') else {}
        blocked = {crop for crop, n in plant_demand.items() if n > seeds.get(crop, 0)}

        def _allowed(a):
            if isinstance(a, list) and len(a) >= 2 and (a[0] == 'PLANT') and (a[1] in blocked):
                return ['PASS']
            return a
        _apply_unit_action(obs0.farms[i], s.observation.private, 0, _allowed(farmer_action), board_size, day, turns_per_day, shed_capacity)
        for h_idx, hand_action in enumerate(hands_actions):
            _apply_unit_action(obs0.farms[i], s.observation.private, h_idx + 1, _allowed(hand_action), board_size, day, turns_per_day, shed_capacity)
    _process_market(state, env)
    _town_consume(env, state, step)
    for farm in obs0.farms:
        _decay_plants(farm, step)
    if (step + 1) % turns_per_day == 0:
        _end_of_day(state, env, day)
    next_step = step + 1
    obs0.day = next_step // turns_per_day
    obs0.hour = next_step % turns_per_day
    for i in range(1, num_agents):
        state[i].observation.farms = obs0.farms
        state[i].observation.market = obs0.market
        state[i].observation.town = obs0.town
        state[i].observation.day = obs0.day
        state[i].observation.hour = obs0.hour
    if step >= cfg.episodeSteps - 2:
        for s in state:
            s.status = 'DONE'
            s.reward = float(obs0.farms[s.observation.player]['money'])
    return state
