任务：《压缩奇点》（The Compression Singularity）—— 两阶段盲测 C++20 程序合成

【阶段一：实验室破译期】
当前工作区提供 6 指令单带比特虚拟机规范、C++20 参考虚拟机（engine/vm.cpp）与 8 组不贴标签的匿名标本（data/samples/specimen_1.in ～ specimen_8.in，每组 L = 10^5）。
测试集由若干个未知的确定性计算家族生成，每个匿名标本对应一个隐藏生成家族。请自行编写脚本分析标本比特流，反向识别其隐藏生成机制，并设计通用自动化分析与字节码合成算法。

【阶段二：暗箱泛化压测期（交付物）】
提交单文件 C++20 自动化求解器至 `../submissions/compression_singularity.cpp`（由 `g++ -std=gnu++20 -O2 -pipe` 编译，含标准 main，单线程，无网络，不调用外部模型）。
正式评测将在离线盲测环境中，针对上述未知家族动态更换全新随机种子与内部参数重新生成 512 个测试点（每家族 32 组 L=10^5 + 32 组 L=10^6），单点限时 60 s / 内存 1024 MiB 喂入你的求解器，并将输出的程序 P 送入参考虚拟机精确校验。

【输入输出与虚拟机语义】
stdin：第 1 行整数 L，第 2 行长度为 L 的 0/1 串 S。
stdout：单行合法虚拟机程序 P（仅含 > < + . [ ]，括号严格匹配，1 <= |P| <= 2L + 100）。
虚拟机初始：ip=0, p=0, T(x)=0, O="", t=0；护栏：t <= 3 * 10^12，|p| <= 10^7，物理校验 <= 600 s。
每步 t += 1：
  `>` : p += 1; ip += 1
  `<` : p -= 1; ip += 1
  `+` : T(p) ^= 1; ip += 1
  `.` : O += T(p); ip += 1
  `[` : if T(p)==0 then ip = match(ip)+1 else ip += 1
  `]` : if T(p)==1 then ip = match(ip)+1 else ip += 1

【评分】
基准 B_ref = 8 * len(lzma.compress(pack_msb(S), FORMAT_RAW, [LZMA2 preset=9]))。
单点不封顶原分：RawScore(P) = 100 * B_ref / (|P| * log2(6))；
单点百分制折算分：NormScore(r) = 100 * r^0.75 / (r^0.75 + 1000^0.75)（r=1000 对应 50.00 分）。
