| 题目类型 | 提交语言与路径 | 求解器限制 | 虚拟机核心护栏 | 虚拟机物理兜底 |
|---|---|---|---|---|

## 一、形式化问题定义

给定一个长度为 $L$ 的目标二进制串 $S = s_0 s_1 \cdots s_{L-1} \in \{0, 1\}^L$（正式测试点满足 $10^5 \le L \le 10^6$）。你需要提交一个独立运行的 **C++20 自动分析与程序合成求解器**，读入 `(L, S)` 后，输出一段能在下方确定性单带比特虚拟机上精确生成 $S$ 的合法程序 $P$，**最小化程序长度 $|P|$**。

> **生成源说明**：测试集由若干个未知的确定性计算家族生成。本工作区提供了一组不贴标签的匿名标本（`data/samples/specimen_1.in` ～ `specimen_8.in`，每组 $L = 10^5$），每个标本对应一个隐藏生成家族；正式评测将在离线盲测环境中针对这些未知家族动态更换全新随机种子与内部生成参数，批量重新生成不同规模的测试点以检验你求解器的真正泛化破译能力。

### 1. 程序语法

定义指令字母表 $\Sigma = \{\texttt{>},\, \texttt{<},\, \texttt{+},\, \texttt{.},\, \texttt{[},\, \texttt{]}\}$（共 $6$ 个字符）。一段长度为 $n = |P| \ge 1$ 的字符串 $P = P_0 P_1 \cdots P_{n-1} \in \Sigma^n$ 称为**合法程序**，当且仅当其中方括号严格匹配：定义前缀括号深度 $d(0) = 0$，对所有 $0 \le i < n$ 有

$$
d(i+1) = \begin{cases} d(i) + 1, & P_i = \texttt{[}, \\ d(i) - 1, & P_i = \texttt{]}, \\ d(i), & \text{否则}, \end{cases}
$$

满足对所有 $0 \le i \le n$ 均有 $d(i) \ge 0$ 且 $d(n) = 0$。此时存在唯一的对称配对双射 $\operatorname{match}(\cdot)$，将每个左括号下标与其对应的右括号下标互为映射。

### 2. 机器状态与操作语义

考虑一台配备双向无限延伸比特带（坐标集为 $\mathbb{Z}$）的确定性机器。机器的瞬时构型由五元组 $(ip,\, p,\, T,\, O,\, t)$ 描述：

- $ip \in \{0, 1, \dots, n\}$ 为指令指针，初始值 $ip = 0$；
- $p \in \mathbb{Z}$ 为读写头坐标，初始值 $p = 0$；
- $T : \mathbb{Z} \to \{0, 1\}$ 为比特带状态函数，初始对一切 $x \in \mathbb{Z}$ 均有 $T(x) = 0$；
- $O \in \{0, 1\}^*$ 为输出流，初始为空串 $\varepsilon$；
- $t \in \mathbb{N}$ 为已执行的原始指令总数，初始值 $t = 0$。

当 $0 \le ip < n$ 时，机器按如下确定性规则执行单步状态转移（每执行一条原始指令均令 $t := t + 1$）：

| 当前指令 $P_{ip}$ | 状态转移规则 |
|---|---|
| `>` | $p := p + 1,\quad ip := ip + 1$ |
| `<` | $p := p - 1,\quad ip := ip + 1$ |
| `+` | $T(p) := 1 - T(p),\quad ip := ip + 1$ |
| `.` | $O := O \cdot T(p),\quad ip := ip + 1$ |
| `[` | 若 $T(p) = 0$，则 $ip := \operatorname{match}(ip) + 1$；否则 $ip := ip + 1$ |
| `]` | 若 $T(p) = 1$，则 $ip := \operatorname{match}(ip) + 1$；否则 $ip := ip + 1$ |

### 3. 停机、越界与优化目标

在执行过程中，每步按严格顺序检查护栏条件：

1. **步数护栏**：若在需要执行下一条指令（$ip < n$）时已有 $t = M = 3 \times 10^{12}$，则机器强制中止并判定为超时（`STEP_LIMIT_EXCEEDED`）。
2. **空间护栏**：若当前读写头坐标满足 $|p| > 10^7$，则机器强制中止并判定为越界（`TAPE_OUT_OF_BOUNDS`）。
3. **正常停机与输出校验**：当且仅当 $ip = n$ 且此前未触发任何中止条件时，程序正常结束。若停机时的输出流 $O$ 与目标串 $S$ 逐位完全一致（即 $|O| = L$ 且 $\forall\, 0 \le j < L,\; O_j = s_j$），则称 $P$ 为针对 $S$ 的一个**有效解**。

> **等价提前终止说明**：若某步执行 `.` 后导致 $|O| > L$ 或新追加的比特与 $S$ 对应位置不等，评测机立即提前中止并判为 `OUTPUT_MISMATCH`，其判定结果与完整运行至停机完全等价。

**任务**：在探索期自主破译匿名标本背后的计算规律，编写单文件 C++20 自动化求解器，使之在面对任意全新未知参数的 $(L, S)$ 时，自动识别机制并构造有效解 $P$，**最小化程序长度 $|P|$**。

## 三、评分标准

### 1. 基准信息量 $B_{\text{ref}}$

对每个测试点，评测系统预先计算基准通用压缩器对 $S$ 压缩后的有效信息比特数 $B_{\text{ref}} > 0$：

- 将 $S$ 按高位优先（MSB-first）紧凑打包为 $\lceil L/8 \rceil$ 字节（末字节低位补 `0`）；
- 使用统一标准库 `liblzma`（Python `lzma.compress(raw_bytes, format=lzma.FORMAT_RAW, filters=[{"id": lzma.FILTER_LZMA2, "preset": 9}])`）压缩所得纯有效载荷字节数乘以 $8$（不含容器头尾）。

### 2. 单题不封顶原分与套题百分制折算

选手程序 $P$ 的理论编码信息量定义为 $|P| \cdot \log_2 6$ 比特。若 $P$ 通过全部合法性与输出校验，该测试点的**原分（不封顶）**为：

$$
\operatorname{RawScore}(P) = 100 \cdot \frac{B_{\text{ref}}}{|P| \cdot \log_2 6}
$$

- 任意非法/超时/越界/错误输出（`CE`、`RE`、`TLE`、`MLE`、`OLE`、`SYNTAX_ERROR`、`PROGRAM_TOO_LONG`、`STEP_LIMIT_EXCEEDED`、`TAPE_OUT_OF_BOUNDS`、`OUTPUT_MISMATCH`、`VM_TIMEOUT`）该点均计 $0$ 分。
- 若仅实现传统字典或熵编码解压器，原分约停留在 $100$ 分量级；若逆向发现 $S$ 的隐藏生成机理并合成极短生成程序（$|P| \ll B_{\text{ref}}$），原分无理论封顶。

为与多题套卷的 0–100 等权总分体系平滑衔接，每个测试点同步计算单调饱和折算分：

$$
\operatorname{NormScore}(r) = 100 \cdot \frac{r^{0.75}}{r^{0.75} + 1000^{0.75}}
$$

| 单点原分 $r = \operatorname{RawScore}(P)$ | 物理含义 | 百分制折算分 $\operatorname{NormScore}(r)$ |
|---|---|---|
| $0$ | 未通过校验 | `0.00` |
| $25$ | 朴素硬编码量级 | `5.92` |
| $100$ | 与 `lzma -9` 持平 | `15.10` |
| $1000$ | 超越 `lzma -9` 10 倍 | **`50.00`** |
| $10000$ | 超越 `lzma -9` 100 倍 | `84.90` |
| $100000$ | 超越 `lzma -9` 1000 倍 | `96.93` |

### 3. 正式评测规模与多点汇总口径

- **正式测试规模**：共 **`512` 个动态隐藏测试点**（`8` 个隐藏生成家族 × 每家族 `64` 测，其中每家族含 `32` 组 $L = 10^5$ 与 `32` 组 $L = 10^6$，全部由操作系统 CSPRNG 动态更换种子与内部参数生成）。
- **正式总分（排序与套题计分主分，满分 `100`）**：取全部 `512` 个测试点 **`NormScore` 的等权算术平均**（每个测试点权重恒为 $1/512$，每个隐藏家族等权占 $1/8$）。
- **强饱和收益提示**：当单点原分超过 $\operatorname{RawScore} > 10\,000$ 后，$\operatorname{NormScore}$ 增幅显著放缓（从 `10,000` 提升 10 倍至 `100,000` 仅增加约 `12.03` 分，而将一个失败家族从 `0` 提升至 `1000` 即可带来该家族 `+50.00` 分）。因此**广覆盖破译多个未知家族的收益远高于在单一家族上追逐极值压缩**。
- **不封顶附加诊断指标**：成绩单同时报告全部 `512` 测 **`RawScore` 的等权算术平均**（无理论上限，作为单题附加诊断指标与同分次级参考，不替代 `NormScore` 主分）。

## 四、样例与形式化追踪

> 注：为便于展示，样例 `00_example` 长度 $L = 20$ 小于正式数据下限 $10^5$。

### 样例输入（`data/samples/00_example.in`）

```text
20
11110111101111011110
```

### 样例输出（`data/samples/00_example.out`）

```text
+>+>+>+[....+.<]
```

### 样例执行追踪

程序长度 $|P| = 16$（下标 $0 \sim 15$，其中 $\operatorname{match}(7) = 15,\; \operatorname{match}(15) = 7$）：

1. **初始化阶段（第 $1 \sim 7$ 步）**：执行 `+>+>+>+`，依次将 $T(0), T(1), T(2), T(3)$ 置为 `1`，完毕后 $p = 3,\; ip = 7$。
2. **进入循环（第 $8$ 步）**：执行下标 $7$ 的 `[`，因 $T(3) = 1$，不跳转，$ip := 8$。
3. **循环迭代（第 $9 \sim 40$ 步，共 $4$ 轮，每轮 $8$ 步）**：
   - 对当前格 $p \in \{3, 2, 1, 0\}$，执行 `....` 追加 `1111`，执行 `+` 将 $T(p)$ 翻转为 `0`，执行 `.` 追加 `0`，执行 `<` 左移至 $p - 1$；
   - 执行下标 $15$ 的 `]`：前 $3$ 轮因 $T(p - 1) = 1$，直接跳回下标 $\operatorname{match}(15) + 1 = 8$（不重复执行 `[`）；第 $4$ 轮移至 $p = -1$，因 $T(-1) = 0$，不跳转，$ip := 16 = |P|$，正常停机。
4. **验证结果**：累计执行 $t = 40 \le 3 \times 10^{12}$ 步，访问区间 $[-1, 3] \subseteq [-10^7, 10^7]$，输出流 $O = \texttt{11110111101111011110} = S$，`AC`。

---

## 五、关键边界条件说明

1. **闭括号 `]` 的精确回跳语义**：执行 `]` 且当前格 $T(p) = 1$ 时，$ip$ 直接跳至 $\operatorname{match}(ip) + 1$（配对 `[` 的**下一条**指令），而非回到 `[` 本身。特别地，空循环 `[]` 在进入前若当前格为 `1`，将在 `]` 处死循环直至耗尽 $3 \times 10^{12}$ 步判 `STEP_LIMIT_EXCEEDED`。
2. **计步口径与优化无关**：参考虚拟机对连续位移/翻转/输出以及任意步长纯寻零循环（如 `[>]`、`[>>]`、`[<<]`）做宏步加速以压低墙钟耗时，但步数 $t$ 严格按展开后的**原始指令条数**累加（例如 `[>^s]` 跨越 $d$ 步遇 `0` 退出精确计 $1 + (s + 1)d$ 步），且越界与步限触发顺序与逐条执行完全一致。
3. **时间换空间策略**：在 $L = 10^6$ 时，程序平均每输出 $1$ 比特享有 $3 \times 10^6$ 步预算；可在不触碰 $3 \times 10^{12}$ 步与 $600\text{ s}$ 红线的前提下，通过高复用慢循环极限压低 $|P|$。
