# 竞赛规则与评测口径 · 压缩奇点

## 1. 两阶段评测机制

- **阶段一（实验室破译期）**：在当前沙盒工作区内阅读虚拟机规范、分析 8 组匿名标本（`data/samples/specimen_1.in` ～ `specimen_8.in`，$L = 10^5$），设计并调试通用 C++20 自动化求解器。
- **阶段二（暗箱泛化压测期）**：在无网络、无外部模型的离线评测环境中，针对这些未知确定性计算家族动态更换全新随机种子与内部参数，重新生成 **512 个正式测试点**（每个隐藏家族 32 组 $L = 10^5$ + 32 组 $L = 10^6$），批量喂给你的求解器并经确定性虚拟机精确校验。

## 2. 提交与资源限制

- 提交单个 C++20 源文件：`../submissions/compression_singularity.cpp`
- 编译命令：`g++ -std=gnu++20 -O2 -pipe`
- 求解器限制：单测试点 CPU / 墙钟限时 60 s，内存上限 1024 MiB，单线程执行，禁止读写工作区外文件、联网或启动子进程。
- 虚拟机校验限制：程序长度 $1 \le |P| \le 2L + 100$，原始步数上限 $M = 3 \times 10^{12}$，读写头范围 $|p| \le 10^7$，物理校验限时 600 s。

## 3. 计分口径

1. 对每个测试点预先计算 $B_{\text{ref}} = 8 \times |\text{LZMA2\_RAW\_preset9}(\text{pack\_msb}(S))|$。
2. 若输出程序 $P$ 在虚拟机中正常停机且逐位输出 $S$，则该点：
   - 不封顶原分：$r = 100 \cdot \dfrac{B_{\text{ref}}}{|P| \cdot \log_2 6}$
   - 百分制折算分：$s = 100 \cdot \dfrac{r^{0.75}}{r^{0.75} + 1000^{0.75}}$
3. 否则（`CE`/`RE`/`TLE`/`MLE`/`OLE`/`SYNTAX_ERROR`/`PROGRAM_TOO_LONG`/`STEP_LIMIT_EXCEEDED`/`TAPE_OUT_OF_BOUNDS`/`OUTPUT_MISMATCH`/`VM_TIMEOUT`），该点 $r = 0,\; s = 0$。
4. 正式总分（排序与套题计分主分，满分 100）为全部 512 个测试点百分制折算分（`NormScore`）的等权算术平均（单点 `RawScore > 10,000` 后 `NormScore` 强饱和，广覆盖多家族优先于单一家族极值压缩）；成绩单同时报告全部 512 测 `RawScore` 均值作为不封顶附加诊断指标。
