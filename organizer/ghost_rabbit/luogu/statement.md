## 题目背景

这是一道**在线交互几何追截题**。

在无限延伸的二维艾森斯坦蜂窝图 $\mathcal{H}_\omega$ 上，潜伏着一只位置不可见的**天翼幽灵兔**。对局开始前，你需要先向评测器自报你的陷阱补给速率 $q = P / Q$；随后在有限回合与有限封锁格数内，结合每轮一次全图声呐测距、艾森斯坦素数跃迁闪光与幽灵弹开反馈，在**局部等距无三连共线（Local 3-AP-Free）**的几何限制下彻底封死兔子的所有合法出路。

你声明的速率 $q$ 越低，成功捕获后的得分越高。

## 题目描述

### 1. 艾森斯坦蜂窝图 $\mathcal{H}_\omega$ 与精确图距离

定义蜂窝图点集为所有模 $3$ 非零的整数格点：

$$V(\mathcal{H}_\omega) = \{(a, b) \in \mathbb{Z}^2 \mid (a + b) \bmod 3 \in \{1, 2\}\}$$

其中 $(x \bmod 3) \in \{0, 1, 2\}$ 取非负最小余数。$\mathcal{H}_\omega$ 为 $3$-正则无限二分图：

- **1-步邻域 $N_1(a, b)$**：
  - 若 $(a + b) \bmod 3 = 1$：$N_1(a, b) = \{(a+1, b),\; (a, b+1),\; (a-1, b-1)\}$；
  - 若 $(a + b) \bmod 3 = 2$：$N_1(a, b) = \{(a-1, b),\; (a, b-1),\; (a+1, b+1)\}$。
- **2-步邻域 $N_2(a, b)$**：
  $$N_2(a, b) = \{(a, b) + d \mid d \in N_2(0, 0)\},\quad N_2(0, 0) = \{(1,-1),(-1,1),(2,1),(-2,-1),(1,2),(-1,-2)\}$$
- **$O(1)$ 三维等距嵌入**：令 $\delta = (a + b) \bmod 3 \in \{1, 2\}$，
  $$\Phi(a, b) = (c_1, c_2, c_3) = \left(\frac{2a - b + \delta}{3},\; \frac{2b - a + \delta}{3},\; \frac{-a - b + \delta}{3}\right)$$
  任意两点 $u, v \in V(\mathcal{H}_\omega)$ 的精确最短路距离为 $\operatorname{dist}_{\mathcal{H}_\omega}(u, v) = |c_1(u)-c_1(v)| + |c_2(u)-c_2(v)| + |c_3(u)-c_3(v)|$。

### 2. 艾森斯坦素数洞穴集合 $\mathcal{P}_\omega$

格点 $(a, b) \in V(\mathcal{H}_\omega)$ 属于 $\mathcal{P}_\omega$，当且仅当满足以下之一：

1. $a = 0$、$b = 0$ 或 $a = b$，且 $r = \max(|a|, |b|)$ 为满足 $r \equiv 2 \pmod 3$ 的有理素数；
2. $a \ne 0,\; b \ne 0,\; a \ne b$，且 $N(a, b) = a^2 - ab + b^2$ 为满足 $p \equiv 1 \pmod 3$ 的有理素数。

兔子初始位置固定为 $r_0 = (1, 0) \notin \mathcal{P}_\omega$。

### 3. 精确有理漏桶

对局开始前，你输出两个正整数 $P, Q$（$1 \le Q \le 10^6,\; 1 \le P \le 2Q$），评测器将其约分为最简分数 $P'/Q'$（$q = P'/Q'$）。

- 初始代币 $\text{tokens} = 0$，容量上限 $2Q'$；
- 第 $t$ 轮开始时，先补给 $\text{tokens} \leftarrow \min(\text{tokens} + P', 2Q')$；
- 本轮允许尝试放置 $k_t \in \{0, 1, 2\}$ 枚陷阱，须满足 $k_t Q' \le \text{tokens}$；结算后扣除 $k_t Q'$。

### 4. 局部等距无三连共线（Local 3-AP-Free）与公开校验

记 $F_{\le t-1}$ 为前 $t-1$ 轮已固化陷阱集合，$A_t$ 为本轮尝试放置的 $k_t$ 枚陷阱，临时集合 $S_t = F_{\le t-1} \cup A_t$。**在判定幽灵弹开之前**，评测器强制校验：

1. $k_t \in \{0, 1, 2\}$ 且 $k_t Q' \le \text{tokens}$；
2. $A_t$ 中全部坐标与声呐点 $(p_a, p_b)$ 均满足 $|x|, |y| \le 10^5$ 且属于 $V(\mathcal{H}_\omega)$；
3. $A_t$ 内部互异且均不在 $F_{\le t-1}$ 中；
4. **$S_t$ 满足 Local 3-AP-Free**：不存在三个互异点 $u, v, w \in S_t$ 使 $u + w = 2v$ 且 $\operatorname{dist}_{\mathcal{H}_\omega}(u, w) \le 6$（在 $\mathcal{H}_\omega$ 上严格等价于不存在 $v \in S_t$ 与 $d \in N_2(0, 0)$ 使 $v-d, v, v+d \in S_t$）。

### 5. 幽灵弹开、素数天使翼与移动

公开校验通过后，评测器依次执行：

1. 若存在 $j \in \{1, \dots, k_t\}$ 使第 $j$ 枚落子等于 $r_{t-1}$，则 `bounce_idx = j`，该枚陷阱弹开失效（不进入 $F_{\le t}$，不计入 $|F| \le 4\,000$，不参与后续 3-AP 校验，但仍消耗 $Q'$ 代币）；否则 `bounce_idx = 0`。其余落子永久固化至 $F_{\le t}$。
2. 校验 $|F_{\le t}| \le 4\,000$，超出直接判 `WA`。
3. 若 $r_{t-1} \in \mathcal{P}_\omega$，置 `flash = 1`，合法移动集 $M_t = (N_1(r_{t-1}) \cup N_2(r_{t-1})) \setminus F_{\le t}$（距离 2 跃迁无视中间障碍）；否则置 `flash = 0`，$M_t = N_1(r_{t-1}) \setminus F_{\le t}$。
4. 若 $M_t = \emptyset$：追截成功！评测器输出 `1 0 0 0` 并换行刷新，你必须立即以返回码 `0` 退出且不得再输出多余内容。
5. 若 $M_t \ne \emptyset$：兔子选择 $r_t \in M_t$（兔子移动不受 $[-10^5, 10^5]^2$ 限制），评测器输出 `0 dist flash bounce_idx`，其中 $\text{dist} = \operatorname{dist}_{\mathcal{H}_\omega}((p_a, p_b), r_t)$。
6. 若完成 $T_{\max} = 5\,000$ 轮后仍未捕获，判 `WA`。

## 交互格式

- **阶段一**：输出一行两个整数 `P Q` 并立即刷新缓冲区（`std::flush` / `fflush(stdout)`）。
- **阶段二**：每轮输出一行 `k_t a_1 b_1 ... a_{k_t} b_{k_t} pa pb` 并立即刷新缓冲区；随后从标准输入读入 4 个整数 `status dist flash bounce_idx`。若 `status == 1`，立刻正常结束程序。

## 样例交互

下面是一段 $q = 3/2 = 1.50$ 的 4 回合合法捕获过程：

| 你的输出 | 评测器回传 | 说明 |
|---|---|---|
| `3 2` | *(无)* | 声明 $P'=3, Q'=2$，漏桶上限 $4$ |
| `1 2 0 0 100000` | `0 133333 0 0` | 封锁 $(2,0)$，远场声呐锁定 $r_1=(1,1)$ |
| `2 2 2 0 1 1 0` | `0 0 0 0` | 封锁 $(2,2),(0,1)$，$r_1$ 被迫退回 $r_2=(1,0)$ |
| `1 0 -1 1 1` | `0 0 0 0` | 封锁 $(0,-1)$，$r_2$ 被迫走回 $r_3=(1,1)$ |
| `1 1 0 1 0` | `1 0 0 0` | 封锁 $(1,0)$，$r_3$ 无路可走，捕获 `AC` 后立刻退出 |

## 评分方式

每个测试点独立评判。若未能捕获、违规或 $q \ge 2$，该点得 `0` 分；否则按你声明的最简分数 $q = P'/Q'$ 计算连续得分：

- **题面不封顶原分（在评测信息中展示）**：
  $$\operatorname{RawScore}(q) = \begin{cases} 100 \cdot \dfrac{4Q' - 2P'}{2P' - Q'}, & \dfrac{1}{2} < q < 2 \\ +\infty\;(\text{Singularity}), & q \le \dfrac{1}{2} \end{cases}$$
- **本点折算得分比例（通过 `quitp` 计分，严格等于 $\frac{r}{r+200}$）**：
  $$\text{Ratio}(q) = \min\!\left(1,\; \frac{2Q' - P'}{P' + Q'}\right)$$

常见速率对应得分比例：$q = 1.75 \to 9.09\%$，$q = 1.50 \to 20.00\%$，$q = 1.25 \to 33.33\%$，$q = 1.00 \to 50.00\%$，$q = 0.90 \to 57.89\%$，$q = 0.80 \to 66.67\%$，$q = 0.70 \to 76.47\%$，$q = 0.60 \to 87.50\%$，$q \le 0.50 \to 100.00\%$。
