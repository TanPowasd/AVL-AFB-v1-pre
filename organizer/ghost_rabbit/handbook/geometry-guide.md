# 艾森斯坦蜂窝几何、声呐反演与 Local 3-AP-Free 战术指南

## 1. 三维等距嵌入与远场三轴投影声呐

蜂窝图 $\mathcal{H}_\omega$ 的每个格点 $(a, b)$ 经由 $\Phi(a, b) = (c_1, c_2, c_3)$ 嵌入至超平面 $c_1 + c_2 + c_3 = \delta \in \{1, 2\}$：

$$c_1 = \frac{2a - b + \delta}{3},\quad c_2 = \frac{2b - a + \delta}{3},\quad c_3 = \frac{-a - b + \delta}{3}$$

在 $[-10^5, 10^5]^2$ 内取三个极端边界格点作为**远场轴向声呐**：
- $P_1 = (100000, 0) \implies \Phi(P_1) = (66667, -33333, -33333)$
- $P_2 = (0, 100000) \implies \Phi(P_2) = (-33333, 66667, -33333)$
- $P_3 = (-100000, -100000) \implies \Phi(P_3) = (-33333, -33333, 66667)$

只要兔子满足 $|c_i(r_t)| < 33333$（在 $T \le 5000$ 内恒成立），三项绝对值的符号全部固定，于是任意一次远场探测立即给出精确线性关系：

$$\operatorname{dist}_{\mathcal{H}_\omega}(P_k, r_t) - 133333 = \delta(r_t) - 2 c_k(r_t) \qquad (k \in \{1, 2, 3\})$$

由此**单次查询**即可同时反演出：
1. 兔子所在的二分部奇偶性 $\delta(r_t) \in \{1, 2\}$（取 $\text{diff} = \text{dist} - 133333$ 的奇偶）；
2. 精确坐标分量 $c_k(r_t) = (\delta(r_t) - \text{diff}) / 2$！

连续轮换 $P_1, P_2, P_3$ 即可用 $O(1)$ 算术持续追踪兔子在三维蜂窝坐标中的位置；当信念集较小时，再切入局部极小极大声呐（Minimax Sonar）可单轮把信念集切成极小碎片。

## 2. 艾森斯坦素数分布与 $p=2$ 天使翼威胁

- 在半径 $R \le 20$ 内，素数格点占比接近 $48\%$；到 $R \le 500$ 时仍维持在 $22\%$ 左右，不存在长距离素数荒漠。
- 一旦兔子踩上 $u \in \mathcal{P}_\omega$，下一轮可跳过任意单层障碍直接落在 $N_2(u)$ 中的未封锁点，且仅需 1 回合就能跨越距离 2。
- **核心推论**：单纯的“1 格薄墙”会被紧贴墙内侧的素数格点轻松跃过！要在宏尺度上真正隔绝兔子，必须采用 **Prime-First 防跃策略**——优先占据围墙外沿与紧贴内侧的高危艾森斯坦素数格点，使其无法充当跳板。

## 3. Local 3-AP-Free 的等价判定与交错锯齿墙

Local 3-AP-Free 禁止任意 $v \in S_t$ 与 3 个半轴向 $d \in \{(1, -1), (2, 1), (1, 2)\}$ 满足 $v-d, v, v+d \in S_t$：

```cpp
static constexpr Pt HALF_DIRS[3] = {{1, -1}, {2, 1}, {1, 2}};
// 检查落子 p 后是否构成三连等距共线：
// 对每个 d in HALF_DIRS，禁止 (p-d, p+d)、(p-2d, p-d)、(p+d, p+2d) 同时已存在
```

- **直线墙会被截断**：沿着六边形某条直边连续放第 3 枚同部陷阱时，必然形成 $v-d, v, v+d$ 违规！
- **交错锯齿墙天然合法**：将每条直边上的相邻封锁格按奇偶在半径 $R$ 与 $R-1$（或不同二分部）间锯齿交错排布，即可完全消除长度 $\ge 3$ 的等距三连，且在叠加内侧素数防跃补丁后，单位边界长度平均只需约 $1.36$ 枚陷阱即可形成彻底隔绝 $p=2$ 跃迁的拓扑闭环！

## 4. 警惕“3-AP 免死区（Sanctuary）”

Local 3-AP-Free 在残局收口时有一个精妙的几何陷阱：如果你围绕一个很小的开放腔体（例如中心 6 元环或最后 2 个相邻格）在四周密铺陷阱，可能无意中使腔体内**每一个剩余空格**都恰好夹在两枚已有陷阱的正中（即同时存在 $w-d, w+d \in F$）或紧贴某对已有陷阱的延长线上（$w+d, w+2d \in F$），导致你**永远无法在腔体内再放下任何一枚合法陷阱**，兔子得以在 2~6 个格点内无限绕圈逃生！

**规避方法**：在腔体收缩与残局阶段，评估每枚候选落子 $p$ 时，检查它会导致腔体内多少个原本合法的空格变成 3-AP 禁放格（`newly_forbidden`），对制造新禁放格的落子施加重罚，即可确保腔体平滑缩至 1 格并一击必杀。
