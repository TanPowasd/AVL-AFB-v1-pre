# 6 指令比特虚拟机编程指南（VM Guide）

本手册仅介绍 $\Sigma = \{\texttt{>},\texttt{<},\texttt{+},\texttt{.},\texttt{[},\texttt{]}\}$ 虚拟机的通用底层原语与编译技巧，不含具体目标流假设。

## 1. 基础原语

| 原语 | 指令串 | 效果与前提 |
|---|---|---|
| 清零当前格 | `[+]` | 无论 `T[p]` 是 0 还是 1，结束后 `T[p] = 0`（0 耗 1 步，1 耗 3 步） |
| 置 1 当前格 | `[+]+` | 结束后 `T[p] = 1` |
| 条件分支（if `T[p]==1`） | `[...末位清零]` | 利用 `]` 在 `T[p]==0` 时退出实现单次条件执行 |
| 向右/向左寻零 | `[>]` / `[<]` | 跳过连续的 1 直到首个 0（C++ 参考 VM 内置快速扫描，仍严格计 $2d+1$ 原始步） |
| 等距跨轨寻零 | `[>>]` / `[>>>>]` | 在多轨交错布局上按步长 $s$ 寻零，同样享受 VM 宏步加速（精确计 $1+(s+1)d$ 原始步） |

## 2. 紧凑计数与控制流

- **一元计数循环**（参见 `agents/baselines/rle_loop.cpp`）：在右侧铺 $a$ 个 `1` 并在循环体末尾 `+<]` 逐一擦除，仅用 $2a + |B| + 4$ 字符即可重复执行循环体 $B$ 共 $a$ 次。
- **二进制计数器**：将 $k$ 位二进制计数器按位排布在连续或双轨格中，利用进位传播循环（遇 1 翻 0 继续，遇 0 翻 1 退出），仅需常数级指令长度即可控制 $2^k$ 轮主循环；对于 $L = 10^6$（约 $2^{20}$），20 位二进制计数器仅需数十个指令字符。
- **布尔运算与状态机**：利用单带相邻工作格可组合实现 `COPY`、`XOR`、`AND`、`NOT`、移位与查表分支，进而以紧凑字节码表达任意小状态确定性计算过程。

## 3. 工程自检与保底策略

- **内置轻量级自校验**：求解器在生成候选紧凑程序 $P$ 后，建议内置轻量级模拟校验输出（至少覆盖全长或核心边界），并估算总步数不超过 $3 \times 10^{12}$、读写头不超过 $[-10^7, 10^7]$。
- **多候选择优 + 兜底回退**：针对同一输入可并行尝试多种压缩/合成模型，校验合法后取 $|P|$ 最短者；若所有高阶模型均未命中，则回退到经验证的通用编码器，确保 **绝不因单个测试点失误得 0 分**。
- **警惕 `]` 语义细节**：当 `T[p] == 1` 时，`]` 直接跳至 `match(ip) + 1`，**不会**重新执行 `[`；设计空循环或边界条件时务必以此为准。
