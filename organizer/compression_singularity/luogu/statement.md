## 题目背景

通用无损压缩器（如 LZ77、LZMA、BWT）依赖重复子串与统计偏置。然而，许多看似高度随机的二进制序列实际上由极短的确定性计算程序生成——它们的柯尔莫哥洛夫复杂度远小于其统计熵。

本题要求你编写一个全自动程序合成求解器：读入一段未知来源的目标二进制串 $S$，逆向识别其潜在的确定性计算规律，并编译出能在极简 6 指令单带比特虚拟机上精确还原 $S$ 的极短字节码 $P$。

> **测试集与附件说明**：测试集由若干个未知的确定性计算家族生成。题目附件（`samples_attachment.zip`）中提供了 1 组微型语法样例（`00_example.in/.out`）、4 组不贴标签的匿名标本（`specimen_1.in` ～ `specimen_4.in`，每组 $L = 10^5$，分别对应一个隐藏生成家族）以及起步模板 `starter.cpp` 与游程基线 `rle_loop.cpp`。正式评测测试点针对这些隐藏家族全部更换了全新的随机种子与内部生成参数，用于检验求解器的真实泛化破译能力。

## 题目描述

给定一个长度为 $L$ 的目标二进制串 $S = s_0 s_1 \cdots s_{L-1} \in \{0, 1\}^L$。你需要输出一段在下方确定性单带比特虚拟机上能够精确生成 $S$ 的合法程序 $P$，**最小化程序长度 $|P|$**。

### 1. 程序语法

指令字母表为 $\Sigma = \{\texttt{>},\, \texttt{<},\, \texttt{+},\, \texttt{.},\, \texttt{[},\, \texttt{]}\}$（共 $6$ 个字符）。长度为 $n = |P| \ge 1$ 的字符串 $P = P_0 P_1 \cdots P_{n-1} \in \Sigma^n$ 称为**合法程序**，当且仅当方括号严格匹配：定义前缀深度 $d(0) = 0$，

$$
d(i+1) = \begin{cases} d(i) + 1, & P_i = \texttt{[}, \\ d(i) - 1, & P_i = \texttt{]}, \\ d(i), & \text{否则}, \end{cases}
$$

满足对所有 $0 \le i \le n$ 有 $d(i) \ge 0$ 且 $d(n) = 0$。记唯一对称配对映射为 $\operatorname{match}(\cdot)$。

### 2. 虚拟机状态与语义

机器配备一条坐标集为 $\mathbb{Z}$ 的双向无限延伸比特带，瞬时构型由五元组 $(ip,\, p,\, T,\, O,\, t)$ 描述：

- $ip \in \{0, 1, \dots, n\}$ 为指令指针，初值 $ip = 0$；
- $p \in \mathbb{Z}$ 为读写头坐标，初值 $p = 0$；
- $T : \mathbb{Z} \to \{0, 1\}$ 为比特带状态，初始全为 $0$；
- $O \in \{0, 1\}^*$ 为输出流，初始为空串 $\varepsilon$；
- $t \in \mathbb{N}$ 为已执行的原始指令总数，初值 $t = 0$。

当 $0 \le ip < n$ 时，每步执行一条原始指令并令 $t := t + 1$：

| 指令 $P_{ip}$ | 状态转移规则 |
|---|---|
| `>` | $p := p + 1,\quad ip := ip + 1$ |
| `<` | $p := p - 1,\quad ip := ip + 1$ |
| `+` | $T(p) := 1 - T(p),\quad ip := ip + 1$ |
| `.` | $O := O \cdot T(p),\quad ip := ip + 1$ |
| `[` | 若 $T(p) = 0$，则 $ip := \operatorname{match}(ip) + 1$；否则 $ip := ip + 1$ |
| `]` | 若 $T(p) = 1$，则 $ip := \operatorname{match}(ip) + 1$；否则 $ip := ip + 1$ |

### 3. 停机、护栏与合法性约束

执行过程中按顺序严格检查以下硬约束：

1. **程序长度上限**：$1 \le |P| \le 2L + 100$（超长判 `PROGRAM_TOO_LONG`，得 $0$ 分）。
2. **确定性步数护栏**：若在需要执行下一条指令（$ip < n$）时已有 $t = M = 2 \times 10^9$，强制中止并判 `STEP_LIMIT_EXCEEDED`（严格按展开后的原始指令条数计步）。
3. **空间护栏**：任意时刻若 $|p| > 10^7$，强制中止并判 `TAPE_OUT_OF_BOUNDS`。
4. **物理兜底时限**：单测试点 SPJ 虚拟机校验耗时超过 $3.5\text{ s}$ 时中止并判 `VM_TIMEOUT`。
5. **输出精确匹配**：正常停机（$ip = n$）且停机时输出流 $O$ 与 $S$ 逐位一致（一旦输出位与 $S$ 不符或长度超出 $L$，SPJ 立即提前终止并判 `OUTPUT_MISMATCH`）。

## 输入格式

第一行一个正整数 $L$，表示目标二进制串的长度。

第二行一个长度为 $L$、仅包含字符 `'0'` 和 `'1'` 的字符串 $S$。

---

## 输出格式

输出一行合法程序字符串 $P \in \Sigma^*$。

仅允许输出末尾存在至多一个换行符（`\n` 或 `\r\n`）；内部及首尾禁止出现空格、制表符、注释、多余空行或 $\Sigma$ 以外的任何字符。

---

### 输入 #1

+>+>+>+[....+.<]

## 说明/提示

### 样例追踪

样例输出长度为 $|P| = 16$（其中 $\operatorname{match}(7) = 15,\; \operatorname{match}(15) = 7$）：

1. 第 $1 \sim 7$ 步执行 `+>+>+>+`，将 $T(0), T(1), T(2), T(3)$ 置为 `1`，随后 $p = 3,\; ip = 7$。
2. 第 $8$ 步执行 `[`，因 $T(3) = 1$ 进入循环（$ip := 8$）。
3. 第 $9 \sim 40$ 步共迭代 $4$ 轮（每轮 $8$ 步）：对当前格输出 `1111`，执行 `+` 翻转为 `0`，输出 `0`，左移一格；前 $3$ 轮在 `]` 处因 $T(p - 1) = 1$ 直接跳回下标 $\operatorname{match}(15) + 1 = 8$（不重复执行 `[`），第 $4$ 轮移至 $p = -1$ 因 $T(-1) = 0$ 退出并停机。
4. 累计执行 $t = 40 \le 2 \times 10^9$ 步，访问区间 $[-1, 3] \subseteq [-10^7, 10^7]$，输出 $O = S$，通过校验。

> **注意闭括号 `]` 语义**：当 $T(p) = 1$ 时，`]` 直接跳至 $\operatorname{match}(ip) + 1$（配对 `[` 的下一条指令），而非回到 `[`。特别地，空循环 `[]` 在 $T(p) = 1$ 时将死循环直至耗尽步数上限。

### 评分标准（Special Judge 部分分）

对每个测试点，后台已预先计算标准压缩基准 $B_{\text{ref}}$（将 $S$ 按 MSB-first 打包为 $\lceil L/8 \rceil$ 字节后，用标准 `liblzma` 的 `FORMAT_RAW + FILTER_LZMA2 (preset=9)` 压缩得到的纯载荷比特数）。

若程序 $P$ 通过全部校验，定义不封顶原分为：

$$
r = \operatorname{RawScore}(P) = 100 \cdot \frac{B_{\text{ref}}}{|P| \cdot \log_2 6}
$$

本题启用 Special Judge（`testlib.h` 的 `quitp` 比例计分），每个测试点的得分比例为单调饱和函数：

$$
\text{ratio}(r) = \frac{r^{0.75}}{r^{0.75} + 1000^{0.75}} \in (0, 1)
$$

| 原分 $r$ | 物理含义 | 单点得分比例（`NormScore`） |
|---|---|---|
| $0$ | 未通过校验 | `0.00%` |
| $25$ | 朴素硬编码量级 | `5.92%` |
| $100$ | 与 `lzma -9` 持平 | `15.10%` |
| $1000$ | 超越 `lzma -9` 10 倍 | **`50.00%`** |
| $10000$ | 超越 `lzma -9` 100 倍 | `84.90%` |
| $100000$ | 超越 `lzma -9` 1000 倍 | `96.93%` |

每个测试点的评测反馈信息中将同时显示精确的 `|P|`、`B_ref`、`RawScore`、`NormScore` 与执行步数 `steps`。

### 数据规模与限制

- 正式隐藏测试集共 **16 个测试点**：4 个隐藏家族各 4 组（每家族 2 组 $L = 10^5$ + 2 组 $L = 5 \times 10^5$），测试点编号已打乱。
- 单测试点求解器限制：时间 **$5\text{ s}$**，内存 **$512\text{ MiB}$**。
- 虚拟机硬护栏：$|P| \le 2L + 100$，原始步数 $t \le 2 \times 10^9$，读写头 $|p| \le 10^7$，SPJ 物理兜底 $3.5\text{ s}$。
