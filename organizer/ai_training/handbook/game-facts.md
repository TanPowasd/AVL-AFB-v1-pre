# 游戏事实卡（前沿实验室精确数值与公式）

全部数值直接核自 `engine/engine.py`、`engine/world.py` 与 `engine/archive.py`。量纲：资金 `M`（百万美元）、参数量 `N` 与数据量 `D` 为 `B`（十亿）、算力 `G1·h`、API 价格为「美元 / 百万 token」（送达 `x` B token 收入为 `x * price / 1000` M）。

---

## 1. 时间、起始状态与通信配额

- **时间单位**：`DAY = 24`、`WEEK = 168`、`MONTH = 730`、`QUARTER = 2190`、`YEAR = 8760`、`TICKS = 26280`（`t = 0 .. 26279`，共 `1095` 天、`157` 周）。
- **开局配置（双方完全对称）**：
  - 现金 `START_CASH = 200.0 M`，创始人股权 `equity = 1.0`，声誉 `rep = 0.0`（范围 `[-3.0, 0.0]`）；
  - 0 号地区机房 `1` 座（初始 `2.0 MW`，该地区 `cap_mw >= 8.0 MW`），自有已装机 `G1` `512` 张；
  - 初始研究员 `20` 人（能力 `1..4` 按 `0.3/0.4/0.2/0.1` 抽样，薪资 `0.0001 * (0.5 + 0.5 * ab) * U(0.9, 1.2)` M/tick）；
  - 仅持有初始公共数据；开局 API 份额 `N1 = 0.5`、`N2 = 0.5`，双方为 `0`。
- **破产**：连续 `BANKRUPT_TICKS = 720` tick（30 天）`cash < 0` 触发破产，清空任务/租约/员工/待结算竞标、下架已上线模型并**清除 `pending_models`**，终局估值锁定为清算价 `equity * max(0, cash + 0.3 * hw)`。
- **提交与进程限额**：`.zip` 压缩 `<= 64 MiB`、解压 `<= 256 MiB`、条目 `<= 2048`、压缩比 `<= 100×`；单行输出 `MAX_LINE_BYTES = 1 MiB`、队列 `MAX_QUEUE_SIZE = 64`；每 tick 列表型动作 `MAX_ACT_ITEMS = 64`（`fire` 上限 `300`）；同 tick 双方动作按 `(t + seed) % 2` 交替执行。

## 2. 五代 GPU、拍卖、云租与二手出售

| 型号 | 单卡算力 (`power`) | 单卡功耗 (`kw`) | 上市季度 (`launch_q`) | 每季供给 (`supply_q`) | 基准单价 (`price`, M) | 算力/价 | 算力/kW |
|:---:|---:|---:|---:|---:|---:|---:|---:|
| `G1` | 1.0 | 0.7 | 0 (t=0) | 8192 | 0.05 | 20.0 | 1.43 |
| `G2` | 2.2 | 1.0 | 1 (t=2190) | 6144 | 0.09 | 24.4 | 2.20 |
| `G3` | 5.0 | 1.4 | 3 (t=6570) | 4096 | 0.17 | 29.4 | 3.57 |
| `G4` | 11.0 | 1.8 | 6 (t=13140) | 3072 | 0.32 | 34.4 | 6.11 |
| `G5` | 24.0 | 2.4 | 10 (t=21900) | 2048 | 0.60 | 40.0 | 10.00 |

- **每周拍卖**：每批 `LOT = 256` 张（单次上限 `64` 批；`lots == 0` 撤单，`lots < 0` 或 `price <= 0` 记非法），每周放出季度供给的 `1/13`（累积取整）；保留价 `reserve = 0.8 * price * heat`。**出清前资金预检**：各玩家可参与批数截断为 `min(lots, floor(max(0, cash) / (price * 256)))`，无现金支撑的报价不参与出清也不影响出清价。统一出清价 `clear = max(reserve, 最高未完全成交报价)`；同价余额不足平分时每家分 `floor(left / 同价人数)`，余数流拍。交付延迟 `4..10` 周。解锁 `early_supply` 后，`G3/G4/G5` 可在上市前 `1` 个季度参与 `25%` 提前配额拍卖（NPC 不参与）。
- **云租**：不占机房电力、不计电费。池容量 `pool = 2 * supply_q`；占用率 `u = clip(clip(0.3 + 0.6 * (heat - 0.75), 0.15, 0.85) + 双方在租 / pool, 0, 1)`；按需单价 `price / 8000 * (1 + 2 * u)` M/(卡·tick)；`spot` 现货为按需的 `0.4` 倍，但每 tick 有 `0.02 + 0.08 * u` 概率整体被抢占（发 `preempted` 事件）并中断创建最晚的、用到该型号的在跑任务（发 `preempt` 事件，回退至最近存档、停 `2` tick、不坏卡）。
- **二手出售**：市场折价上限 `mkt_unit = price * SELL_RATE[behind] * min(1.0, heat)`（当代 `0.65`、落后 1 代 `0.50`、落后 `>= 2` 代 `0.30`），按出库批次结算每张卡回款 `min(mkt_unit, batch_unit_cost) * max(0, 1 - (t - arrival_t) / HW_LIFE)`，`SELL_DELAY = 48` tick 到账（恒低于拍卖保留价且不超过剩余硬件账面）。

## 3. 机房、电力与 PPA

- `5` 个地区：基础电价 `U(0.0004, 0.0012)` M/MWh，单座容量上限 `cap_mw` `U(5, 40)` MW（0 号地区 `>= 8` MW），建站工期 `8..20` 周，监管系数 `reg` `U(0.8, 1.5)`。
- 机房数量上限 `8` 座（同地区可重复建）；`build_site` 完工直接获得全部 `cap_mw`；`expand_site` 花费 `2.0 M/MW`、`8` 周（`1344` tick）完工。
- **装机硬约束**：`sum(cards * kw) * PUE <= site_mw * 1000`（默认 `PUE = 1.30`，解锁 `cooling` 后 `1.15`；地区限电期间上限 `×0.7`，超限按比例不可用）。
- **电价曲线**：`base_price * (1 + 0.12 * t / 8760) * (1 + 0.1 * sin(2π * t / 8760 + phase))`。
- **用电量**：训练卡按满功率，服务卡按 `0.3 + 0.7 * 利用率`。
- **PPA 锁电**：锁定签约时该地区电价 `×0.8`，持续 `8760` tick，每 tick 照付不议扣 `(mwh / 8760) * 锁定价`；单座机房同时生效上限 `MAX_PPA_PER_SITE = 64` 份。

## 4. 研究员与科技树（共 18 项）

- 每周人才池 `10..30` 人，能力 `1..5`（概率 `0.30/0.30/0.20/0.13/0.07`），显示 `[lo, lo+2]` 与 `ask`，约 `12%` 有 NPC 竞价。在职员工上限 `MAX_STAFF = 300` 人，每 tick 产出等于其能力值 `ab` 的研究点。
- **挖角 `poach`**：每周处理前 `5` 条，`salary <= 0` 记非法，受 `MAX_STAFF = 300` 限制。
  - 挖对手（`opp`）：每周上限 `POACH_OPP_MAX = 2` 次（同 `idx` 去重），成功挖走后进入 `POACH_OPP_COOLDOWN = 2` 周冷却；成功须现金支付 `POACH_OPP_SIGNING = 336` tick 薪资签约金（现金不足失败）。成功率 `sigmoid(3 * (sal / 现薪 - 1.3) - (0.5 + 在职年数))`。
  - 挖 NPC（`N1`/`N2`）：成功须现金支付 `POACH_NPC_SIGNING = 168` tick 薪资签约金；成功率 `sigmoid(3 * (sal / 0.0003 - 1.3) - 1.0)`，能力按次独立随机 `1..5`。
- **解雇 `fire`**：每人立即扣除 `FIRE_SEVERANCE = 168` tick 薪资遣散费。
- 核心研究员离职：每月公共随机数 `< 0.02` 时双方各离职能力最高的一人。

| 科技 ID | 研究点 | 前置 | 效果 |
|---|---:|---|---|
| `algo_eff_1` / `2` / `3` | 20k / 60k / 150k | 依次前置 | 新建训练任务有效参数 `N_eff = N × 1.15 / 1.30 / 1.50` |
| `stable` | 30k | 无 | 超学习率尖峰触发概率减半 |
| `curriculum` | 40k | 无 | `set_mix` 不再触发每次 `×0.95` 的数据效率惩罚 |
| `infer_opt_1` / `2` | 25k / 70k | 依次前置 | API 推理算力消耗 `×0.80` / `×0.60` |
| `synth` | 35k | 无 | 解锁 `synth` 合成数据生成 |
| `early_supply` | 50k | 无 | `G3/G4/G5` 提前 1 季度参与 `25%` 拍卖配额 |
| `cooling` | 20k | 无 | 全部机房 `PUE` 由 `1.30` 降至 `1.15` 并立即触发装机 |
| `filter:<domain>`（8 个域） | 各 25k | 无 | 揭示该域真实 `q` 与减半后 `c`，并将此后训练污染减半 |

## 5. 数据池、合成与蒸馏

- **9 个训练数据池**：7 个真实评测域（`web, code, math, books, science, dialog, multiling`）+ `synth` + `distill`。
- **公共初始去重量 `PUBLIC_B`（每种子乘 `U(0.6, 1.4)`）**：`web 2000`, `code 400`, `math 60`, `books 300`, `science 150`, `dialog 100`, `multiling 800`, `synth 10`（单位 B）。
- **质量与污染**：真实域 `q in [0.5, 1.5]`、`c in [0, 0.12]`；`synth` 初始 `q in [0.6, 0.9]`、`c = 0`；`init` 给出带 `U(-0.3, 0.3)` 误差的 `q_hint`。
- **有效 token 衰减**：$E_k = 4 U_k (1 - \exp(-S_k / (4 U_k))) \cdot \bar{q}_k$（训练 4 轮约得 `2.53 U`）。
- **迁移矩阵 $T_{d,k}$**：同域 `1.0`；强跨域如 `math←code (0.4..0.7)`、`dialog←multiling (0.3..0.6)`、`science←books (0.3..0.5)`、`dialog←web (0.2..0.4)`、`math←science (0.2..0.4)`、`code←web (0.1..0.25)`；`synth` 对各域 `0.25..0.40`；`distill` 对各域 `0.40..0.60`；其余 `0.02..0.12`。
- **独家数据招标**：每周 `0..2` 份，`tokens_b in [50, 500]`，`reserve = tokens_b * 0.03 * heat`，中标独享 `8760` tick 后转入对方公共池。
- **合成数据 `synth`**：花费 `tokens_b * best_N * 100 * G1按需租价`，`24` tick 入库，质量 `0.6 + 0.6 * best_C`，无污染；单任务累计合成占比 `> 0.30` 触发坍缩加性 loss `0.5 * (fs - 0.30)`。
- **蒸馏 `distill`**：花费 `tokens_b * price / 1000`（`OPEN-1` 免费；对手收到全额费用进入现金），立即入池，质量 `0.5 + 0.8 * teacher_C`；存档蒸馏占比 `>= 0.10` 时真实能力封顶 `max_teacher_C - 0.03`；凡本周实际训练过或周一处于 `running/paused/review` 且蒸馏占比 `> 0.20` 的任务，每周一按座位无关公共随机数以 `10%` 概率被诉罚没 `15%` 现金且 `rep -= 0.2`。
- **版权诉讼**：月度训练量中 `web + books` 占比 `> 0.50` 时，当月触发概率 `0.1 * (frac - 0.5) / 0.5`，罚当前现金 `3%`。

## 6. 训练动力学与隐藏缩放律

- **吞吐公式**：
  - `raw = sum(cards_m * power_m)`，`cards = sum(cards_m)`；
  - `util = min(1.0, 2.0 * batch / cards)`；
  - 临界批大小 $B_{\text{crit}} = bc_0 (1 + D/50)^{0.4}$（$bc_0 \in [192, 640]$）；
  - `waste = (min(batch, B_crit) + 0.5 * max(0, batch - B_crit)) / batch`；
  - `work = raw * util * waste * slow * (0.8 if 本tick自动或手动存档 else 1.0)`；
  - 本 tick 前进 token：`tok = work / (300 * N)`。
- **域 Loss 公式**（$d \in \{0..6\}$）：
  $$L_d = \left(E_d + \frac{A}{N_{\text{eff}}^{\alpha}} + \frac{B}{D_{\text{eff}, d}^{\beta}} + P_{\text{lr}} + P_{\text{collapse}}\right) \times M_{\text{spike}} \times (1 - b_{\text{sched}})$$
  - 隐藏参数范围：$\alpha \in [0.28, 0.40]$，$\beta \in [0.25, 0.35]$，$A \in [0.30, 0.60]$，$B \in [0.90, 1.50]$，$E_d \in [1.4, 2.2]$；
  - 最优学习率 $\eta^* = c_{\text{lr}} N^{-0.3}$（$c_{\text{lr}} \in [0.0012, 0.0028]$），默认 `lr` 为 `0.0010 * N^-0.3`；$P_{\text{lr}}$ 为按 token 加权的 $0.08 (\ln(\eta / \eta^*))^2$；
  - 尖峰：当 $\eta > \eta^*$ 时每 tick 概率 $0.002 \exp(3(\eta/\eta^* - 1))$（`stable` 减半），使 $M_{\text{spike}} \times 1.02$，其中 `10%` 触发 `diverged`。存档先于尖峰判定，回滚即可撤销。
  - **退火 $b_{\text{sched}}$ 与 `set_tokens`**：`cosine` 为 `0.02 * min(1, prog)^2`；`wsd` 为 `0.03 * clip(min(prog - 0.85, anneal_tok / target) / 0.15, 0, 1)`，须真实训练 `0.15 * target` 退火 token，进入退火或下调至 `D >= 0.85 * target` 后永久锁定禁止上调；`set_tokens` 禁止用于 `done`/`stopped` 任务且要求 `D < v <= 1e6`；`const` 为 `0`。
- **故障、慢节点与监管审核**：
  - 硬件故障：每 tick 概率 `cards / 50000`，回退最近存档、停 `2` tick、若用自有卡则坏 1 张 `72` tick；
  - 慢节点：每天 `1%` 概率触发，吞吐降 `10%..30%`，`diagnose` 恢复（停 `1` tick）；
  - 监管停审：单任务有效累计算力 `>= 20,000,000 G1·h` 且未审批时强制停审 `336 * reg` tick（`reg` 取最大电力机房所在地区）。

## 7. 能力、API 市场、融资与终局估值

- **能力标定**：6 项任务（`reasoning/coding/knowledge/chat/multilingual/general`）加权 7 域无噪 loss 经 sigmoid 均分得 `C in [0, 1]`（标定基准：小模型 `20B/400B` 约 `0.15..0.25`，大模型 `300B/6T` 约 `0.80..0.90`）。
- **公开榜分与复测**：`pub = C + 加权污染占比`；月度复测若 `pub - C > 0.05`，扣 `rep -= 0.3` 并重置 `pub = C`。
- **API 竞争**：
  - 商业门槛：玩家模型须 `C >= API_MIN_C = 0.15` 才进入旗舰竞争；
  - 旗舰基础效用：$u_{\text{base}} = 6.0 \cdot \text{pub} - 1.5 \ln(\max(\text{price}, 1.0))$，玩家加 `+ rep - 5.0 * drop`；
  - 反价格震荡：周一 logit 迁移（单周上限 `±0.15`）取当前效用、周峰值价效用与周内最差效用三者最小值；周内无能力补偿的提价使 `u_base < anchor_u - 1.5 * ln(1.5)` 时，当前份额当 tick 按 `exp(u_base - (anchor_u - 1.5 * ln(1.5)))` 立即流失并重分给其他方；
  - 声誉演化：上周 `drop > 0.001` 时 `rep -= min(0.1, drop)`，否则 `rep += 0.01`，范围 `[-3.0, 0.0]`。服务 `1 B token/tick` 需 `25 * N * infer_mult` G1 算力。
- **全市场需求**：`Q0 = 5.0 B token/tick`，第 1/2/3 年月增 `8% / 5% / 3%`，乘以 AI 热度（78 周周期正弦 + AR(1)，范围 `[0.6, 1.5]`）与季度冲击（20% 概率 `×0.85` 或 `×1.15`）。
- **全局事件**：出口管制（60% 种子，Q4–Q8 之一 `G3` 供给减半，提前 2 周公告）；开源事件（30% 种子，第 6–24 月，`OPEN-1` 能力=发布 NPC `-0.05`、价 `3`、蒸馏免费，同时 NPC 全线降价 `×0.7`）；NPC 首代 `C in [0.30, 0.50]`，每 `6..9` 月迭代 `+0.05..0.10`（上限 `0.97`），定价 `10 * (0.5 + C) * npc_mult`。
- **季度融资**：每 `2190` tick 限 1 次，`V_pre = min(24 * max(0, GM_2190) + 300 * max(0, 己方最高pub - 他方最高pub) + cash + hw_book + site_book, V_true)`，融资后 `equity *= V_pre / (V_pre + amount)`。
- **终局创始人股权估值**：
  $$\text{Value} = \text{equity} \times \Big(\text{cash} + \text{recv} + \text{hw\_book} + \text{site\_book} + 24 \cdot \text{GM}_{2190} + 300 \cdot C_{\text{best}}\Big)$$
  - 硬件 `3` 年（`26280` tick）线性折旧，机房 `10` 年（`87600` tick）线性折旧；
  - $\text{GM}_{2190}$ 为最后 `1` 季度（`2190` tick）API 收入减去服务卡分摊租金与电费；
  - $C_{\text{best}}$ 仅统计累计在线 `>= 730` tick 的己方模型，或终局未下架且在线 `>= 72` tick 的己方模型（最晚须在 `t = 26183` 观测后提交 `release`）。
