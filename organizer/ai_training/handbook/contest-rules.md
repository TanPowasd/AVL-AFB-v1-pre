# 前沿实验室（Frontier Lab）公开赛制与评分规则

本文件仅包含公开赛制与评分口径，权威实现以 `engine/engine.py`、`engine/world.py` 与 `engine/archive.py` 为准。

## 1. 比赛形式与胜负目标

- **模拟周期**：一局共 `26280` tick（`3` 年 = `1095` 天 × `24` 小时，`1` tick = `1` 小时）。
- **隐藏世界**：每个场景种子独立生成缩放律常数、跨域迁移矩阵、域质量与污染率、最优学习率常数、临界批大小、地区机房参数及全局事件序列。对抗双方共享同一世界序列与对称公共随机数，且同 tick 动作执行顺序按 `(t + seed) % 2` 交替，交换座位公平对称。
- **双赛制同卷评测**：同一份提交同时参加单人赛与对抗赛，协议中不提供赛制标记。
  1. **单人赛（占 50%）**：你固定坐 `0` 号座位，背景对手为内置固定脚本 `engine/solo_npc.py`。每局得分为 `100 * C`，其中 `C` 为三年内符合资格的最高已上线模型真实能力；取各种子平均得 `solo`。
  2. **对抗赛（占 50%）**：与 `4` 个固定参考对手逐一在每个种子下交换座位对局。每局比较双方终局创始人股权估值 `Value`，按冻结映射尺度 `12710.23 M` 计算：
     $$s = 50 + 50\tanh\left(\frac{Value_T - Value_R}{12710.23}\right)$$
     对全部对手、种子与座位等权平均得 `adv`（持平为 `50` 分）。
  3. **总分（满分 100）**：`score = 0.5 * solo + 0.5 * adv`（`scoring_version = "scoring_v2"`）。
- **默认样本量**：正式评测默认每次从操作系统安全随机源抽取 `N = 64` 个不重复场景种子（单人赛 `64` 局 + 对抗赛 `4 × 64 × 2 = 512` 局，共 `576` 局），报告附带 95% 种子块 bootstrap 区间。
- **世界盐值**：本地练习工具固定使用 `practice` 盐值，正式评测使用私有盐值；同一整数种子在本地与正式环境中生成的世界不同。

## 2. 交付格式与运行限制

- **提交路径**：统一提交至 `../submissions/ai_training.zip`（根目录含 `main.py`，推荐使用 `python scripts/make_submission.py <目录> --out ../submissions/ai_training.zip` 打包校验；独立单题开发可暂存于 `agents/submissions/my_agent.zip` 或目录）。
- **压缩包配额与安全**：压缩后 `<= 64 MiB`、解压后 `<= 256 MiB`、条目 `<= 2048`、单文件压缩比 `<= 100×`；禁止加密条目、符号链接/非常规文件、路径穿越、Windows 保留名及非法字符、大小写冲突路径或文件遮蔽目录。损坏或不合规压缩包将在加载阶段判故障并得 `0` 分。
- **语言与依赖**：UTF-8 Python 3.10+，仅允许使用 Python 标准库；禁止联网、禁止读写包外文件、禁止读取对手源码。包内只读数据请相对 `Path(__file__).resolve().parent` 读取。
- **进程通信**：独立子进程由 `engine/pkg_entry.py` 启动根目录 `main.py`，工作目录为包目录，`stderr` 被丢弃，`PYTHONHASHSEED=0`、`PYTHONUTF8=1`，经 `stdin / stdout` 逐行交互 UTF-8 JSON。
- **时限、输出上限与容错**：
  - `init` 握手限时 `10.0` 秒；
  - 单 tick 基础限时 `2.0` 秒 + 整局共享不回补时间池 `120.0` 秒（余额见 `obs["time_pool"]`）；
  - 整局累计思考预算 `2400` 秒（40 分钟）；终局 `end` 回复限时 `1.0` 秒；
  - 单行输出上限 `1 MiB`，未消费行缓冲上限 `64` 行，超限立即终止进程；
  - 单 tick 超时或非法 JSON 按 `{}` 处理并记录 `missed`；未回复消息积压满 `50` 条、崩溃或总预算耗尽后，后续全按 `{}` 处理；
  - 动作含 `NaN`、`Infinity` 或绝对值 `> 1e15` 的数字时整步作废；列表型动作单 tick 上限 `64` 条（`fire` 上限 `300` 条）；字段异常时该项及后续动作作废。

## 3. 自测与工作区红线

- 本地自测仅允许使用公开陪练（`blank`、`scaling`、`merchant`、`--solo`）或自身镜像对局，严禁与其他参赛提交互测或读取其他选手工作区、成绩、回放与日志。
- 自测产物须保存在当前工作区的 `results/`、`replays/`、`logs/` 目录；打包输出仅限 `agents/submissions/` 或 `../submissions/ai_training.zip`。
- 严禁修改引擎、`config/format.json`、`config/workspace.json` 或公开基线；选手工作区禁止 `--unrestricted` 与 `--serve`。
- 正式评测由裁判方在正式评测环境中统一执行。
