# 0016 r9：世界池买卖点差、采掘入仓次优先级、开局禀赋永久豁免与规则引擎对齐

- 日期：2026-11-15
- 状态：**已采纳**（用户批准 `A1`–`A5` 五项平衡性与规则一致性修订）。
- 规则版本：`rift_era_rules_r8` → **`rift_era_rules_r9`**。按 [AGENTS.md](../AGENTS.md) 第 4 条发布新规则版本；六份规则 JSON 的 `version`/`status` 与各章状态行同步为 `rift_era_rules_r9`。`data/round6_scenarios.json`、`data/review_cases.json` 仍按历史记录保留原版本号。

## 背景

在 [决策0014](0014_r7_opening_balance_and_world_pool.md)（r7）与 [决策0015](0015_r8_emissions_and_endowment_phase_in.md)（r8）完成实装及三档对手对局复盘后，发现以下平衡性与规则—引擎一致性问题：

1. **世界池零点差双向套利（E12）**：r7–r8 世界池对所有库存货按同一固定价 `10·w_cat` RU 同时买卖，导致高阶策略可以按零点差把富余初级品换成 RU 再按平价买回高复杂度制品（如直接停掉本土钢厂/水泥厂改由世界池平价进口），削弱了本土工业链与国家间双边贸易的价格空间。
2. **采掘满仓挤死民生制造（E10）**：无空间调控或初级策略在原矿/水持续采掘堆满公共仓后，同阶段一视同仁按比例分配剩余仓容，采掘原矿与食品/药品等制造产出同池抢仓，且采掘场缺乏运行开关命令，易形成“原矿塞满仓库 → 制造停摆 → 原矿更无法消耗”的死锁。
3. **开局禀赋在 20 周期退出后重新压垮 `eta_sink`（E2）**：r8 的 20 周期线性退出仅缓解前 5–15 周期；第 21 周期起，尚未消耗完的开局缓冲库存重新全额计入 `I_physical_eta`，使正常经营国的工业支柱再次低于“开局停产”。
4. **开局医疗/农业余量偏紧（E3/E11）与空厂壳刷控制分（E8）**：开局 `P033` 仅 0.2 批、初始 `medicine` 120 单位，在未及时解锁 `A04` 扩产或外购时约 78 周期断药；`farm_fertility=1.1` 在局地污染上升后粮食余量极薄；同时，只建工业厂壳而不装机不排产即可按 100% 账面成本计入 `Kinfra`。
5. **三处规则—引擎口径差异**：
   - `military/interdict` 缺少 `03 §7` 与 `06` 要求的迷雾可见性（`q >= 0.2`）、编队射程校验、观测者独立在途接触别名（`11 §4`），且海运/空运承运工具火力通道映射存在错位；
   - 被占领枢纽居民持有原主权国本币储蓄时无法通过有限池真实换汇用于本地民生消费（`02` 末节“消费换汇仍走真实对手”），且 `truce_dmz(mode=cession)` 移交国有产权与经营权时未同步移交底层物理资产经营归属；
   - 跨境电力合同（`03 §5` type 1 电力子项 / `E12`）周期末退还超限价差额时仅查卖方能源公司 RU 户，未在判违约前动用卖方主权 `reserves` RU 兜底。

## 决定

### 1. 世界池双向点差（A1，`runtime_rules.world_pool`、[02](../02_economy_logistics_governance.md)、[06](../06_agent_interface.md)）

- 保留中点参考锚 `price_w_cat_multiplier = 10`（`10·w_cat` RU/单位），新增：
  - **买入乘数 `buy_price_w_cat_multiplier = 11.5`**：`trade/pool_buy` 单位买价为 `ceil(11.5 · w_cat · 1000)` mU RU（较目录锚溢价 `+15%`）；
  - **卖出乘数 `sell_price_w_cat_multiplier = 8.5`**：`trade/pool_sell` 单位卖价为 `floor(8.5 · w_cat · 1000)` mU RU（较目录锚折价 `-15%`）。
- 保留每国、每种库存货、每个方向每周期 `40` 单位上限，保留 P1 预锁与 P5 有限池同比缩量规则。世界池定位回归“有成本的应急采购与折价泄洪渠道”，双边贸易与枢纽市场在中点区间 `[8.5·w_cat, 11.5·w_cat]` 内自然具备双赢成交空间。

### 2. 公共仓容制造优先与采掘场运行开关（A2，[01](../01_world_and_realtime.md)、[05](../05_industry_system.md)、[06](../06_agent_interface.md)）

- **两遍出库仓容仲裁**：同一枢纽 `P6` 产出释放竞争剩余公共仓容 `C_free` 时，先由**非采掘制造产线**按 `01` 无偏等比规则分配第一遍仓容并扣除其实际释放载重，剩余仓容再由**采掘线（`G1/G2`）**按同一无偏等比规则分配第二遍仓容。原矿与采水不再挤占同拍食品、药品及工业品的入库空间。
- **`industry/plant_toggle` 扩展支持采掘场**：`facility_id` 同时接受本国电站设施 ID 或采掘场 ID（`mine_id`）。对采掘场设 `online=false` 时暂停该矿场的取水预约、供电预约、人工占用与 `P6` 采掘推进（可随时设 `online=true` 恢复），观测 `mines[]` 同步报告 `online: bool`。

### 3. 开局非回填禀赋余量永久豁免 `eta_sink` 库存分子（A3，`scoring.json`、[07](../07_scoring_and_resources.md)）

- 取消 r8 的 20 周期线性相入系数 `(20-k)/20`，改为**整局永久豁免未消耗的开局非回填禀赋余量**：
  - `E0[p,g]` 为 `T=0` 国家 `p` 在全部地点的初始实物库存；
  - `R[p,g]` 每拍更新为 `min(上一拍 R[p,g], 当前全部地点实物库存 I_physical_all[p,g])`，只减不增、生产或购入永不回填；
  - 任意周期 `I_physical_eta[p,g] = I_physical_all[p,g] - min(R[p,g], I_physical_all[p,g])`。
- 一旦开局缓冲被消耗，`R[p,g]` 永久下降，后续一切新增累库均 100% 计入 `I_physical_eta`；既消除开局缓冲造成的“停产优于生产”倒挂，又保持对后续盲目堆库存的完整消纳约束。

### 4. 开局医疗/农业余量上调与闲置工业空壳 `Kinfra` 折算（A4，`runtime_rules.initial_world`、`scoring.json`、[01](../01_world_and_realtime.md)、[07](../07_scoring_and_resources.md)）

- **开局模板微调（保持总人口 `194+6=200` 与 Hub0 自然水上限 `<=32` 不变）**：
  - `load_overrides.P033`：`0.2 → 0.5`（开局药品产出由约 `0.40` 升至约 `0.94`/周期，耗用既有富余化学品/玻璃/生物质，总人工与总取水仍留正余量）；
  - `farm_fertility`：`1.1 → 1.25`（3 座 `P028` 基准产粮由 `13.2` 升至 `15.0`/周期，不增加耗水与人工，增强抗污染与人口增长缓冲）；
  - 初始现货微调：`medicine: 120 → 160`、`food: 180 → 210`、`grain: 90 → 120`（无命令断药窗口延至约 `160` 周期 = `1,600` tick，留足研发 `A04` 或贸易调配时间）。
- **未装机闲置工业空壳 `Kinfra` 按 25% 计入**：已建成非住宅工业设施（`S1–S5`）若其下属产线非空且全部处于未装机无配方空置状态（`recipe == __idle__` 且公共槽未安装系统模块），在 `Kinfra` 中仅按 `0.25` 倍账面残值计入；一旦任一产线配置有效配方或安装公共槽系统模块即恢复 `1.0` 倍，堵住纯造空壳刷控制分的退化策略。

### 5. 三项规则—引擎严格对齐（A5，[02](../02_economy_logistics_governance.md)、[03](../03_warfare_diplomacy_intelligence.md)、[06](../06_agent_interface.md)、[11](../11_execution_contract.md)）

1. **在途截击迷雾、射程、接触别名与域通道修复**：
   - 观测 `military.shipment_contacts` 向各观察方下发当前可见（所在走廊两端至少一端对观察方 `q >= 0.2`）外国在途运输的观测者独立接触别名 `contact_id`（`11 §4`，绝不暴露创建国内部序号）；
   - `military/interdict` 接受 `contact_id`（或兼容字段名 `shipment_track_id` / `shipment_id`），强制校验目标当前对发起方可见（`q >= 0.2`）且处于执行编队有效射程跳数内（陆路近战射程为 0 时须位于该边两端分区之一），否则返回 `ERR_NO_VISIBLE_TARGET` / `ERR_SITE_INCOMPATIBLE`；
   - 承运工具截击火力通道按物理域映射：`freighter → sea`、`transport_aircraft / air_drone → air`，其余陆运工具为 `ground`。
2. **占领区居民异币储蓄真实换汇消费与和约割让物理移交**：
   - 当被占领或易手枢纽的常住居民在控制国本币户余额不足以覆盖当拍民生采购需求，且该枢纽居民池仍持有原主权国等其他主权币种储蓄时，缺口部分自动通过 `WorldClearPool` 执行两腿真实即期换汇（`原币 → RU → 控制国本币`，受有限池余额与手续费约束，严格保持 `cash_book` 与货币总量守恒），落实 `02`“消费换汇仍走真实对手”；
   - `truce_dmz(mode=cession)` 生效移交出让方主权分区时，对未质押且产权与 `operator` 一并移交接收国的已建成国有设施、产线、采掘场、公共槽系统与仓库，在当拍末观测边界前完成底层物理经营归属（`owner`、虚拟资本账与维护目标）同步过户，接收国自下一拍起可直接下令调度。
3. **跨境电力合同退差额兜底顺序**：
   - 周期末结算跨境电力合同超限价退款时，先从卖方 `corp:energy` RU 账户扣付，不足部分再从卖方主权 `reserves` RU 账户补足；仅当两账户合计仍不足以退清超限差额时，才对未退清残额触发合同违约与信用扣减。
