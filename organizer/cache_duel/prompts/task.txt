## 2. 一句话规则

双角色在线缓存攻防博弈：攻击方每步发出一个请求 key（仅看到上一步 `last_hit`），防守方在缓存满且缺失时决定驱逐哪一个 key。终局按离线最优 **Belady/MIN** 缺失数 `OPT` 与防守实际缺失数 `M_def` 计分：

- 防守得分：`def_score = OPT / M_def ∈ (0, 1]`（越大越好）
- 攻击得分：`att_score = 1 - def_score ∈ [0, 1)`（越大越好）
- 综合总分：`0.5 * 防守均分(0~100) + 0.5 * 攻击均分(0~100)`

- **纯标准库**：仅允许 Python 标准库；`stderr` 被丢弃；环境变量固定 `PYTHONHASHSEED=0`；工作目录为提交文件所在目录。

- **类型校验**：`key` 与 `evict` 必须是纯 `int`（`bool` 如 `True`/`False`、`float`、`None` 均判犯规！），且 `0 <= key < K`、`evict in current_cache`。
- **时间限制**：

## 5. 六个高频策略与工程坑（省你半天）

1. **忘记 `flush=True` 或忽略 `need_evict=false` 回复**：`stdout` 缓冲卡死会直接耗光 `1s + 5s` 超时判死，哪怕 `hit=true` 或缓存未满也必须每步回 `{}`。
2. **攻击方在全空间 `K` 均匀随机反而送分**：当 `K=4096, C=64` 时，大范围纯随机请求会让 **Belady OPT 也几乎步步缺失**，导致 `OPT / M_def → 1`，攻击分接近 `0`！高攻击分的核心是制造**“OPT 很容易命中、在线防守方却反复踩空”**的访问模式（例如集中在约 `C+1 ~ 2C` 的工作集、结合 `last_hit` 探测对手驱逐策略与周期相位变化）。
3. **纯确定性防守会被 `C+1` 扫穿**：LRU 和 FIFO 面对 `t % (C+1)` 缺失率都是 `100%`（`C=64` 时 `def_score` 低至 `~1/64`）；必须结合**随机化**（如 Marking / 随机淘汰权重）与**在线模式检测**（区分扫描攻击、热点+扫描混合、自适应回踩与局部性工作集）。
4. **防守本地缓存集合与裁判脱节**：如果漏更新命中/装入/驱逐，导致提交了不在缓存内的 `evict`，裁判会强制驱逐**最新放入的 key**，立刻造成连续雪崩缺失。务必确保本地 `cache` 更新与 `engine.py` 逐行等价。
5. **`N=5000, K=4096` 下的性能陷阱**：20 秒总预算摊到 5000 步仅 `4ms/步`（含 JSON I/O）。避免每步扫描全键空间 `O(K)`，把单步复杂度控制在 `O(1)` 或 `O(C)`（`C <= 64`）。
6. **硬编码配置尺寸或忽略随机种子**：正式评测覆盖 `(8, 64, 3000)`、`(32, 256, 5000)`、`(64, 4096, 5000)` 三组配置并每次更换 OS 随机种子。所有窗口/集合规模须由开局消息中的 `C, K, N` 计算，随机数使用 `random.Random(init["seed"])`。

## 2. `stdin / stdout` 逐行 JSON 通信协议

每一条消息均为**单行合法 UTF-8 JSON**，以换行符 `\n` 结尾，每次回复必须立即刷新缓冲（`flush=True` 或 `sys.stdout.flush()`）。

### 阶段 1：初始化握手（启动后第 1 行）
- **裁判发送**：
  ```json
  {"role": "attacker", "cache_size": 8, "universe": 64, "length": 3000, "seed": 2847192014}
  ```
  - `role`：`"attacker"` 或 `"defender"`
  - `cache_size`（`C`）：缓存容量（正整数）
  - `universe`（`K`）：合法 key 范围 `0 .. K - 1`（`K > C`）
  - `length`（`N`）：本局总步数 `t = 0 .. N - 1`
  - `seed`：由场景种子按角色哈希派生，攻防双方不同；请用 `random.Random(init["seed"])` 保证可复现
- **Bot 回复**：任意合法 JSON 对象（如 `{}`）并 `flush`。

### 阶段 2：逐步交互（`t = 0, 1, ..., N - 1`）

#### 若 `role == "attacker"`
- **裁判发送**：
  ```json
  {"t": 0, "last_hit": null, "time_pool": 5.0}
  ```
  - `t = 0` 时 `last_hit` 为 `null`；`t > 0` 时为上一步请求是否命中的布尔值 `true` / `false`。
  - 攻击方**看不到**防守方当前缓存集合，也看不到被驱逐的 key。
- **Bot 回复**：
  ```json
  {"key": 7}
  ```
  - `key` 必须是整数（不能是 `bool` 或 `float`），且 `0 <= key < K`。

#### 若 `role == "defender"`
- **裁判发送**：
  ```json
  {"t": 12, "key": 7, "hit": false, "need_evict": true, "time_pool": 4.982}
  ```
  - `key`：本步攻击方实际请求的 key（已包含攻击方犯规时的替代结果）。
  - `hit`：`key` 当前是否已在缓存集合中。
  - `need_evict`：当且仅当 `hit == false` 且当前缓存已满（`len(cache) == C`）时为 `true`。
- **Bot 回复**：
  - 当 `need_evict == true`：`{"evict": e}`，`e` 必须是当前缓存集合内的整数（非 `bool`）。裁判随后移除 `e` 并将 `key` 加入缓存。
  - 当 `need_evict == false`：回复 `{}`（**不可省略**！裁判仍会等待这一行回复）。

### 阶段 3：对局结束
- **裁判发送**：`{"t": N, "end": true}`
- **Bot 回复**：回复 `{}` 并退出循环结束进程。

# 游戏事实卡（Cache Duel，全部核对自 `engine/engine.py`、`config/format.json` 与公开基线源码）

## 1. 官方三组评测配置（`config/format.json`）

| 配置索引 | 缓存容量 `C` | 键空间 `K` | 总步数 `N` | 空间比 `K / C` |
|---:|---:|---:|---:|---:|
| `0` | `8` | `64` | `3000` | `8` |
| `1` | `32` | `256` | `5000` | `8` |
| `2` | `64` | `4096` | `5000` | `64` |

## 2. 引擎与计时常量（`engine/engine.py`）

- `STEP_TIMEOUT = 1.0` 秒：单步基础时限。
- `TIME_POOL = 5.0` 秒：每局共享时间池，每次 `dt > 1.0` 扣除 `dt - 1.0`，不回补。
- `TOTAL_BUDGET = 20.0` 秒：每个 bot 单局累计思考时间上限；每次询问的实际超时阈值为 `min(STEP_TIMEOUT + pool, max(0.0, TOTAL_BUDGET - used))`。
- 角色随机种子派生：
  `role_seed(seed, role) = int(sha256(f"{seed}|{role}").hexdigest()[:8], 16)`
  攻击方与防守方拿到的 `seed` 相互独立，无法互相反推。
- 合法 key 类型判定：`is_key(v)` 要求 `isinstance(v, int) and not isinstance(v, bool)`。
- 犯规替代与技术判负：
  - 攻击方非法输出 / 死亡后：该步 key 替换为常量 `0`。
  - 防守方在 `need_evict == True` 时非法输出 / 死亡后：驱逐 `insert_order[-1]`（即当前缓存中**最晚装入**的 key；注意 `insert_order` 按插入顺序维护，命中不改变其位置）。
  - 正式评分（`scoring_v2`）与 `spar.py` 对犯规/超时/崩溃实行零容忍技术判负：本方该局一旦出现 `faults > 0` 或 `dead == True`，该局直接计 `0` 分。

## 3. 离线最优（Belady / MIN）与计分公式

给定实际请求序列 `R = (r_0, ..., r_{N-1})` 与容量 `C`：
- 对每个位置 `i`，定义下一次出现位置 `nxt[i]`；若 `r_i` 之后不再出现，引擎赋以唯一大值 `n + i`（平手按索引更大者优先驱逐）。
- 每次缺失且缓存已满时，Belady 算法驱逐当前缓存中 `nxt` 最大的 key，得到最小可能缺失次数 `OPT = belady_misses(R, C)`。
- 记防守方实际缺失数为 `M_def`：
  - 若 `M_def == 0`，`def_score = 1.0`；否则 `def_score = OPT / M_def ∈ (0, 1]`。
  - 攻击方该局得分：`att_score = 1 - def_score ∈ [0, 1)`。
- 重要推论：
  - 攻击方想拿高分，必须拉大 `M_def` 与 `OPT` 的比值（降低 `OPT / M_def`），而不是单纯提高 `M_def`。若攻击序列毫无规律且覆盖远大于 `C` 的键空间（如在 `K=4096` 上均匀随机），`OPT` 也会接近 `N`，导致 `def_score → 1`、`att_score → 0`。
  - 经典离线-在线竞争比理论界：确定性缓存算法的最坏竞争比下界为 `C`（即 `def_score` 可低至 `1/C`），随机化算法（如 Randomized Marking）对不知情对手（oblivious adversary）可达 `O(H_C) = O(log C)` 竞争比；但本题中攻击方每步都能收到 `last_hit`（自适应对手），因此兼具随机化与自适应检测/反侦察至关重要。

## 4. 四个公开基线精确行为（`agents/baselines/`）

| 短名 | 文件 | 防守策略 | 攻击策略 |
|---|---|---|---|
| `fifo` | `agents/baselines/fifo.py` | 先进先出队列（FIFO），驱逐最早装入的 key | 80% 概率均匀随机访问 `[0, max(1, C//2))` 热键，20% 顺序扫描 `[C//2, K)` 冷键 |
| `lru` | `agents/baselines/lru.py` | 最近最少使用（LRU，`OrderedDict`） | 固定循环扫描 `t % (C + 1)` |
| `marking` | `agents/baselines/marking.py` | 随机化 Marking：命中/装入打标记，驱逐时从无标记集合均匀随机选出；若全有标记则清空重来 | 在 `0..C` 共 `C+1` 个 key 上做随机排列扫描，每轮打乱一次 |
| `rand` | `agents/baselines/rand.py` | 缓存内等概率随机驱逐 | 在 `[0, min(K, 2*C))` 上均匀随机 |

## 5. 正式百分制评测口径（`scoring_v2`）

- 固定参考对手池：`7` 个固定对手（不随参赛提交改变），每份提交在 `3` 组配置 × `64` 个 OS 安全随机种子（`os_csprng`）上分别执攻、执守，共 `7 * 3 * 64 * 2 = 2688` 局。
- 等权聚合：
  - `防守分 = 100 * mean(def_score)`
  - `攻击分 = 100 * mean(1 - 对手 def_score)`
  - `总分 = 0.5 * 防守分 + 0.5 * 攻击分 ∈ [0, 100]`
- 本地 `scripts/spar.py` 与 `scripts/run_match.py` 采用完全一致的单局计分公式，仅对手池替换为公开基线并标记 `official = false`。

"""cache_duel bot 模板：同一个文件同时负责攻击和防守。"""
import json, sys, random

def main():
    init = json.loads(sys.stdin.readline())
    role, C, K, seed = init["role"], init["cache_size"], init["universe"], init["seed"]
    rng = random.Random(seed)
    print("{}", flush=True)                      # 握手
    cache = set()
    for line in sys.stdin:
        msg = json.loads(line)
        if msg.get("end"):
            print("{}", flush=True); break
        if role == "attacker":
            # msg = {"t", "last_hit"}；回 {"key": 0..K-1}
            print(json.dumps({"key": rng.randrange(K)}), flush=True)
        else:
            # msg = {"t", "key", "hit", "need_evict"}；需要驱逐时回 {"evict": 缓存里的某个 key}
            k = msg["key"]; out = {}
            if not msg["hit"]:
                if msg["need_evict"]:
                    e = rng.choice(sorted(cache)); cache.discard(e); out["evict"] = e
                cache.add(k)
            print(json.dumps(out), flush=True)

main()

============================== 官方裁判源码 engine/engine.py（只用于理解，勿整份复制到提交） ==============================

"""cache_duel 对战引擎：一局 = 一个 attacker bot 对一个 defender bot。

协议见 README.md。每个 bot 是一个 Python 文件，
以子进程运行，stdin/stdout 每行一个 UTF-8 JSON。
"""
from __future__ import annotations

import hashlib
import json
import os
import queue
import subprocess
import sys
import threading
import time
from dataclasses import dataclass, field

STEP_TIMEOUT = 1.0      # 单步硬超时（秒）
TIME_POOL = 5.0         # 时间池（秒）：独立于单步，单步超出 1s 的部分从池扣，池空后超 1s 即超时
TOTAL_BUDGET = 20.0     # 每个 bot 每局总思考时间（秒）
MAX_LINE_BYTES = 65536  # 单行回复字节硬上限，防止恶意超大输出耗尽裁判内存
CLOSE_WAIT_S = 2.0      # 发送 end 后等待子进程及沙箱包装器优雅退出与清理的最大时长


class BotError(Exception):
    pass


class Bot:
    def __init__(self, path: str, init: dict):
        self.path = path
        self.used = 0.0
        self.pool = TIME_POOL
        self.dead = False
        self.faults = 0
        env = {
            **os.environ,
            "PYTHONHASHSEED": "0",
            "PYTHONUTF8": "1",
            "PYTHONIOENCODING": "utf-8",
        }
        self.proc = subprocess.Popen(
            [sys.executable, "-u", "-X", "utf8", os.path.abspath(path)],
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.DEVNULL,
            bufsize=0,
            env=env,
            cwd=os.path.dirname(os.path.abspath(path)),
        )
        self.q: queue.Queue = queue.Queue(maxsize=4)
        self._reader_thread = threading.Thread(target=self._reader, daemon=True)
        self._reader_thread.start()
        hs = self.ask(init)  # 握手：bot 需回一行合法 JSON 对象（如 {}）
        if not self.dead and not isinstance(hs, dict):
            self.dead = True
            self.kill()

    def _put_event(self, kind: str, payload) -> bool:
        try:
            self.q.put((kind, payload), timeout=0.5)
            return True
        except queue.Full:
            return False

    def _reader(self):  # 跨平台（Windows 管道不支持 select），带单行字节硬限与 UTF-8 异常兜底
        stdout = self.proc.stdout
        if stdout is None:
            self._put_event("eof", None)
            return
        try:
            while True:
                raw = stdout.readline(MAX_LINE_BYTES + 1)
                if not raw:
                    break
                if len(raw) > MAX_LINE_BYTES and not raw.endswith(b"\n"):
                    self._put_event("oversize", None)
                    return
                try:
                    line = raw.decode("utf-8")
                except UnicodeDecodeError:
                    self._put_event("bad_utf8", None)
                    return
                if not self._put_event("line", line):
                    # 队列积压满：说明子进程无视协议狂刷输出
                    return
        except Exception:
            pass
        self._put_event("eof", None)

    def ask(self, msg: dict):
        if self.dead:
            return None
        try:
            # 发消息前队列若已有未请求的滞留输出，说明子进程提前多行抢跑/刷屏，直接判死
            if not self.q.empty():
                raise BotError("desync")
            payload = (json.dumps(msg, separators=(",", ":")) + "\n").encode("utf-8")
            self.proc.stdin.write(payload)
            self.proc.stdin.flush()
            t0 = time.perf_counter()
            limit = min(STEP_TIMEOUT + self.pool, max(0.0, TOTAL_BUDGET - self.used))
            try:
                kind, line = self.q.get(timeout=limit)
            except queue.Empty:
                raise BotError("timeout")
            dt = time.perf_counter() - t0
            self.used += dt
            self.pool = max(0.0, self.pool - max(0.0, dt - STEP_TIMEOUT))
            if kind != "line" or not line:
                raise BotError(kind)
            return json.loads(line)
        except (BotError, OSError, ValueError, RecursionError):
            self.dead = True
            self.kill()
            return None

    def _close_pipes(self):
        for stream in (self.proc.stdin, self.proc.stdout):
            if stream is not None:
                try:
                    stream.close()
                except Exception:
                    pass

    def close(self, end_msg: dict | None = None):
        """对局结束时优雅通知并等待退出，保证沙箱与 AppContainer Profile 完整清理，不污染 dead 标记。"""
        try:
            if not self.dead and end_msg is not None and self.proc.stdin is not None:
                try:
                    payload = (json.dumps(end_msg, separators=(",", ":")) + "\n").encode("utf-8")
                    self.proc.stdin.write(payload)
                    self.proc.stdin.flush()
                except Exception:
                    pass
                try:
                    self.proc.stdin.close()
                except Exception:
                    pass
                try:
                    self.proc.wait(timeout=CLOSE_WAIT_S)
                    return
                except subprocess.TimeoutExpired:
                    pass
            self.kill()
        finally:
            self._close_pipes()

    def kill(self):
        try:
            if self.proc.poll() is None:
                self.proc.kill()
        except Exception:
            pass
        try:
            self.proc.wait(timeout=CLOSE_WAIT_S)
        except Exception:
            pass
        self._close_pipes()


def belady_misses(trace: list[int], cap: int) -> int:
    """离线最优（Belady/MIN）缺失数。"""
    import heapq
    if cap <= 0:
        return len(trace)
    n = len(trace)
    nxt = [0] * n
    last: dict[int, int] = {}
    for i in range(n - 1, -1, -1):
        nxt[i] = last.get(trace[i], n + i)  # 不再出现时给一个唯一的大值
        last[trace[i]] = i
    cache: dict[int, int] = {}  # key -> 下一次出现位置
    heap: list[tuple[int, int]] = []  # (-next, key)，惰性删除
    misses = 0
    for i, k in enumerate(trace):
        if k in cache:
            cache[k] = nxt[i]
            heapq.heappush(heap, (-nxt[i], k))
            continue
        misses += 1
        if len(cache) >= cap:
            while True:
                nn, kk = heapq.heappop(heap)
                if kk in cache and cache[kk] == -nn:
                    del cache[kk]
                    break
        cache[k] = nxt[i]
        heapq.heappush(heap, (-nxt[i], k))
    return misses


def role_seed(seed: int, role: str) -> int:
    """按角色派生种子，一方无法从自己收到的种子推出对方的随机流。"""
    h = hashlib.sha256(f"{seed}|{role}".encode()).hexdigest()
    return int(h[:8], 16)


def is_key(v) -> bool:
    return isinstance(v, int) and not isinstance(v, bool)


@dataclass
class MatchResult:
    attacker: str
    defender: str
    config: dict
    def_misses: int
    opt_misses: int
    def_score: float          # OPT缺失 / 防守方缺失 ∈ (0,1]，越大防守越好
    faults: dict = field(default_factory=dict)


def play(attacker_path: str, defender_path: str, cache_size: int, universe: int,
         length: int, seed: int) -> MatchResult:
    cfg = {"cache_size": cache_size, "universe": universe, "length": length, "seed": seed}
    att = Bot(attacker_path, {"role": "attacker", **cfg, "seed": role_seed(seed, "attacker")})
    dfd = Bot(defender_path, {"role": "defender", **cfg, "seed": role_seed(seed, "defender")})
    cache: set[int] = set()
    insert_order: list[int] = []  # 用于非法驱逐时的惩罚：驱逐最新放入的
    trace: list[int] = []
    misses = 0
    last_hit = None
    att_faults = def_faults = 0
    try:
        for t in range(length):
            a = att.ask({"t": t, "last_hit": last_hit, "time_pool": round(att.pool, 3)})
            k = a.get("key") if isinstance(a, dict) else None
            if not is_key(k) or not (0 <= k < universe):
                att_faults += 1
                k = 0  # 攻击方失误：退化为常量键 0，杜绝借助犯规白嫖循环扫描攻击
            trace.append(k)
            hit = k in cache
            need_evict = (not hit) and len(cache) >= cache_size
            d = dfd.ask({"t": t, "key": k, "hit": hit, "need_evict": need_evict, "time_pool": round(dfd.pool, 3)})
            if not hit:
                misses += 1
                if need_evict:
                    e = d.get("evict") if isinstance(d, dict) else None
                    if not is_key(e) or e not in cache:
                        def_faults += 1
                        e = insert_order[-1]  # 惩罚：驱逐最新放入的
                    cache.discard(e)
                    insert_order.remove(e)
                cache.add(k)
                insert_order.append(k)
            last_hit = hit
    finally:
        att.close({"t": length, "end": True})
        dfd.close({"t": length, "end": True})
    opt = belady_misses(trace, cache_size)
    return MatchResult(
        attacker=attacker_path, defender=defender_path, config=cfg,
        def_misses=misses, opt_misses=opt, def_score=opt / misses if misses else 1.0,
        faults={"attacker": att_faults, "defender": def_faults,
                "attacker_dead": att.dead, "defender_dead": dfd.dead},
    )
