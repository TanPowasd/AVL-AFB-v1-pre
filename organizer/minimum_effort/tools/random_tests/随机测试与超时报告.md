## 复现

在解压后的根目录执行。三个 `*_reference.csv` 提供样本哈希、标准答案与时限。报告中的通过率对应上述种子和生成规则。

```powershell
g++ -std=c++17 -O2 -pipe leaderboard_profile_search.cpp -o leaderboard.exe
python random_tests/generate_general.py cases/general_19374 --seed 19374
python random_tests/generate_general.py cases/general_981821 --seed 981821
python random_tests/generate_general.py cases/general_73190518 --seed 73190518
python -X utf8 random_tests/generate_fixed.py cases/fixed_571943 --seed 571943 --count 40
python -X utf8 random_tests/generate_fixed.py cases/fixed_812657 --mode construct --seed 812657 --count 32
python random_tests/benchmark.py ./leaderboard.exe cases --reference random_tests/general_reference.csv --csv general.csv
python random_tests/benchmark.py ./leaderboard.exe cases --reference random_tests/fixed_reference.csv --csv fixed.csv
python random_tests/benchmark.py ./leaderboard.exe cases --reference random_tests/fixed_construct_reference.csv --csv fixed_construct.csv
```
