# 双符奇点（The SK Singularity）

## 题目描述

给定一套动态下发的**封闭双符号组合子重写系统** $\mathcal{R} = (a_S, R_S, a_K, R_K)$、微缩规模上限 $N$（$8 \le N \le 24$）、唯一 DAG 节点护栏 $V_{\max}$ 以及可选的**强制残骸子树** $E_{\text{req}}$。

表达式 $E$ 为由符号 `S`、`K` 与二元应用构成的满二叉树，其文法与规模（叶子总数）定义为：

$$E ::= \texttt{S} \mid \texttt{K} \mid \texttt{(} E \; E \texttt{)}, \qquad |\texttt{S}| = |\texttt{K}| = 1, \qquad |\texttt{(} E_1 \; E_2 \texttt{)}| = |E_1| + |E_2|$$

任取表达式 $E$，沿左脊柱唯一写为 $h \, u_0 \, u_1 \dots u_{k-1}$（$h \in \{\texttt{S}, \texttt{K}\}$）。当且仅当 $k = a_h$ 时称 $E$ 为**根部红式**，一步归约将模板 $R_h$ 中的变量 `i` 替换为 $u_i$（字面常量 `S`、`K` 保持不变）。单步**最左最外归约** $\to_{\mathrm{no}}$ 规定：
1. 若 $E$ 为根部红式，直接执行根部归约；
2. 否则对 $E = (E_1 \; E_2)$，若 $E_1$ 非范式则先归约 $E_1$；
3. 否则若 $E_2$ 非范式则归约 $E_2$。

请你编写求解程序，在时限内输出一个合法表达式 $E$，满足：
1. $|E| \le N$；
2. 若 $E_{\text{req}} \ne \texttt{-}$，则 $E$ 包含 $E_{\text{req}}$ 作为完整子树（真子树或自身）；
3. $E$ 在最左最外归约下合法停机，且在 **Hash-Consed 记忆化精确归约引擎**中累计创建的唯一 DAG 节点数不超过 $V_{\max}$（默认 $10^7$）。

在满足约束的前提下，**最大化精确最左最外归约停机步数 $T(E)$**。

> **关键说明**：
> - Hash-Consed `(whnf, nf)` 记忆化引擎与纯树最左最外步数 **100% 严格等价**（被复制的共享子树步数会按出现次数严格累加，绝不漏算；被丢弃分支不会求值），同时支持在 $V_{\max} = 10^7$ 节点内精确验算 $T(E) \gg 2^{1000}$ 的超指数停机步数。
> - `S` 与 `K` 仅为抽象符号名，其元数 $a_S, a_K \in [1, 4]$、模板拓扑与字面常量均由输入动态指定，且可能施加精确的 `S <-> K` 符号对换。

## 输入格式

共 $4$ 行：
- 第 $1$ 行：五个整数 `N a_S a_K V_max TL_ms`（$8 \le N \le 24$，$1 \le a_S, a_K \le 4$）。
- 第 $2$ 行：`S` 的右端满二叉树模板 `RHS_S`（叶子为 `0`..`a_S - 1` 或字面常量 `S`、`K`）。
- 第 $3$ 行：`K` 的右端满二叉树模板 `RHS_K`。
- 第 $4$ 行：强制残骸子树 `E_req`（无约束时为 `-`）。

## 输出格式

仅输出一行合法的 SK 满二叉树表达式 $E$（字符仅含 `S`、`K`、`(`、`)` 及可选 ASCII 空格，总长度 $\le 4096$ 字节，二元应用括号不可省略）。

## 样例

### 样例输入 1
```text
8 3 2 10000000 5000
((0 2) (1 2))
0
-
```

### 样例输出 1
```text
((((S (S ((S S) S))) S) S) K)
```

### 样例说明
该输入为标准 SK 组合逻辑在 $N=8$ 下的实例，样例输出达到该规模下的全局精确极大停机步数 $T(E) = 1958$（$\log_2(1959) \approx 10.9359$）。

## 评分方式

本题采用 Special Judge（`checker.cpp`）按测试点部分分计分。设单测合法停机步数为 $T(E)$，记 $L = \log_2(T(E) + 1)$，该测参考锚点为 $L_{\text{ref}}$，则该测得分比例为：

$$\text{Ratio} = \frac{L^{0.85}}{L^{0.85} + L_{\text{ref}}^{0.85}} \in [0, 1)$$

若语法非法、$|E| > N$、缺少强制残骸、触发环路发散或超出 $V_{\max}$ 唯一 DAG 节点上限，该测得 $0$ 分。
