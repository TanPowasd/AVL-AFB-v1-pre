# 《双符奇点》（sk_singularity）竞赛细则与评测护栏

## 1. 编译与运行隔离

- 编译器与参数：`g++ -std=gnu++20 -O2 -pipe`（独立单文件编译，不添加题库 `engine/` 头文件搜索路径）。
- 单测资源限额：CPU/墙钟时间上限 `5000 ms`（以输入第 1 行 `TL_ms` 为准），峰值内存上限 `1024 MiB`，标准输出上限 `64 KiB`（合法表达式本身须 $\le 4096$ 字节）。
- 沙盒边界：每个测试点在全新空白临时目录中运行，禁止读写外部文件、联网、调用子进程或探测宿主机环境。

## 2. 确定性裁判与唯一 DAG 节点护栏

- 校验内核以 [`engine/sk_core.hpp`](../engine/sk_core.hpp) 为唯一权威实现。
- 步数定义：与纯树最左最外归约（Normal-Order Reduction）100% 严格等价。
- 确定性截断护栏：
  - 唯一 Hash-Consed DAG 节点数上限：`V_max = 10,000,000`（含 2 个基础叶节点 `S`/`K`）；
  - 显式求值栈深度上限：`40,000,000`；
  - 任意环路（`CYCLE_WHNF` / `CYCLE_NF`）直接判定 `DIV`（0 分）；超节点或超栈判定 `NL`（0 分）。
- 步数计数精度：
  - $T(E) < 2^{62}$：精确 64 位无符号整数；
  - $T(E) \ge 2^{62}$：纯整数规格化 63 位尾数 + 64 位指数（round-to-nearest-even），无硬件浮点实现差异，可精确表示 $\log_2(T(E)+1)$ 高达数百万量级的超指数停机步数。

## 3. 正式评分与动态盲规则防硬编码

- 正式评测集包含 **512 个动态生成隐藏测试点**（通过操作系统 CSPRNG 抽取 512 个互异 64-bit 随机种子，覆盖 8 类正交盲规则/残骸家族 × 64 测/家族，每家族在 4 档微缩预算 $N \in \{14, 18, 21, 24\}$ 上各 16 测；所有生成规则严格排除全部公开练习规则及其符号对换同构并在整批 512 测内去重）。
- 每组动态测试点按其随机种子以 50% 概率施加精确的 **`S <-> K` 符号对换同构**（同步对换 `a_S <-> a_K`、`RHS_S <-> RHS_K` 及其中字面常量与 `E_req` 中的 `S`/`K`）。数学上精确最优步数 $T^*(N)$ 严格不变。
- **动态专属锚点标定**：每批次正式评测开始前，使用冻结强参考求解器在**同一批动态测试点**上以短时限 **`600 ms`** 现场求得参考对数步数 $L_{\text{基准}, i}$，按如下规则标定每测专属锚点：
  $$L_{\text{ref}, i} = \operatorname{round}\!\big(\operatorname{clamp}(1.40 \cdot L_{\text{基准}, i},\, 12.0,\, 600.0),\, 2\big)$$
- **单测折算分**：合法停机记 $L = \log_2(T(E) + 1)$（任一错误计 `0`），
  $$\text{NormScore}_i = 100 \cdot \frac{L^{0.85}}{L^{0.85} + L_{\text{ref}, i}^{0.85}} = 100 \cdot \frac{r^{0.85}}{r^{0.85} + 1}, \qquad r = \frac{L}{L_{\text{ref}, i}}$$
  常见倍率锚点：`0.5× -> 35.68`、`1.0× -> 50.00`、`2.0× -> 64.32`、`5.0× -> 79.71`、`10.0× -> 87.62`、`25.0× -> 93.91`。
- 正式总分 = 全部 512 个隐藏测试点 `NormScore` 的等权算术平均（满分 100.00）。成绩单同步公布不封顶 `RawLog2Mean`、`RawLog2Max` 与 `SingularityCount`（$T(E) \ge 2^{64} - 1$ 的测试点数）。

## 4. 本地自测与正式评测的区别

- `scripts/spar.py` 运行在 14 个公开练习测试点（[`config/practice_suite.json`](../config/practice_suite.json)）上，涵盖所有语法形态（元数 `2/3/4`、字面常量注入、强制残骸、反转元数），但公开盲规则与隐藏正式盲规则互不重叠。
- 本地分数仅供参考；避免对公开练习集硬编码查表，应专注于面向任意未知双符号重写系统的通用搜索、探针代数挖掘与高共享结构合成算法。
