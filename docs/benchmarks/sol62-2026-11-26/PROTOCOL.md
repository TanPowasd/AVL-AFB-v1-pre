# Evaluation protocol

- Benchmark commit: `c868c07b2e46abb59ec17ab4987b6f22bd2a5435`. Three independent native GPT-6.2 Sol runs, one per task, no warm-up with other agents. Model ID was requested from the execution platform; no independent backend/model attestation, exact token counter, billing receipt, or exact reasoning-budget counter was exposed. No token estimates are reported. Maximum assignment time: 12 minutes per task, same shell/tool instructions. Tasks did not share prompts or answers. The root evaluator had previously read repository metadata and did not compete. Workers were instructed to use only the provided problem documents; this is not a cryptographically isolated or formally blind model evaluation. SHA-256 receipts identify every provided input file.
- Submitted code was frozen before evaluation and executed in a fresh task-only Bubblewrap fixture with system libraries mapped read-only, environment cleared, Linux PID/user/IPC isolation and a seccomp socket-denial check. Scoring inputs and outputs are not disclosed beyond case hashes and entrant-produced metrics. This is a local Linux setup, not the upstream Windows formal judge or an official leaderboard entry.
- Environment: Linux x86-64, GNU C++ 14.2.0, Python 3.12.14, Bubblewrap 0.12.0. Match seed sets were selected before official scores were viewed. One entrant per task; results are not comparisons across model families. Model response time differs from grader time and in-game algorithm time.
- **Minimum Effort:** upstream manifest and 36 fixed published grading cases, with data checksums verified. Compile `g++ -std=gnu++20 -O2 -pipe solution.cpp -o solution`; run plain stdin/stdout, separately compare normalized output with official expected output. Independent harness records one pass and CPU/RSS, not the upstream three-pass efficiency-adjusted score. Time limit checks use candidate CPU plus a separate wall-clock watchdog; memory limit enforced as address space rather than RSS.
- **Ghost Rabbit:** upstream public practice runner, three public opponent families, seeds 20261126, 424242, 707070, one evaluation worker; command `python3 scripts/spar.py agents/submissions/my_solution.cpp --seed 20261126 424242 707070 --jobs 1`. These are nine practice games, not the 32 official games.
- **Kaggriculture:** upstream public practice runner, three public opponents (passive, random and greedy), three seeds in both seats; command `python3 scripts/spar_with_rows.py agents/submissions/sol62 --all --seeds 20261126 424242 707070`. The wrapper logs per-game results without changing upstream scoring. These are 18 practice games, not the 384 official games. Practice score is not win percentage.
